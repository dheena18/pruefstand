`error` with one automatic retry, never `failure` (D226); `robust_pr` is scored through the target's
`POST /v1/retrieve` without generation, and without the reranker if its lane exceeds 20 min per PR run (D222); the
nightly runs the fixed refusal stratum (all unanswerable cases, ≥ 100 clusters) plus one of 3 stratified blocks,
≤ 600 cases, covering `full` every 3 nights, in the window 22:00–06:00 Europe/Berlin, with cause-switch scenarios
weekly (SPEC §6.2, D223); all Ollama traffic uses the native API with fixed per-model options (D219/D220)), gate
statistics: paired cluster bootstrap by `cluster_id`, the FAIL rule "significant and > δ", gated vs
informational slices, metrics gated only with ≥ 30 applicable clusters (W3.6), one Holm family per run, MDE

test against the measured self-agreement a₀, reported next to κ, AI11-10), `eval_fingerprint` with judge serving

`judge_epoch` while drift never changes it (X3.3), judge input cap = context window − 1 024 with truncated cases
listed (X3.9)) · 4 Datasets (corpus, tenants, canaries, licenses) · 5 Experiments: RQ1 (chunking axis
scored with span-level `evidence_recall` (owner T7.3, X3.2), doc-level `context_recall` secondary (W3.11); e5
≤ 512-token sensitivity row; "fix first" after BH q = 0.10), RQ2 (binary κ per label set on the **full** set; on

- synthetic private docs and a single domain;
- judge bias; no German annotator: judge calibration uses MEMERAG-DE expert labels (other systems'
  answers on MIRACL contexts, not the reference app; CC BY-NC, data not redistributed) and labels
  **true by construction** from GermanQuAD/GermanRAG (no partial credit; constructed negatives such
  as other-question answers are easier than real errors, so overall κ is an upper bound — hence the
  separately gated hard-negative specificity and the in-domain `legal_hard` set, whose positives were reviewed
