## Goal

`GiiXmlLoader` turns each downloaded law (`xml.zip`, `gii-norm.dtd` structure) into `Document`s and
`ParagraphChunker` emits one `Chunk` per § (or Artikel) with a normalised `citation_key`
(e.g. `"§ 622 BGB"`) and `version_date`.

## Context

- GII XML: `<dokumente><norm><metadaten><jurabk>BGB</jurabk><enbez>§ 622</enbez><titel>…</titel>
  <standangabe>…</standangabe></metadaten><textdaten><text><Content><P>(1) …</P>…` .
- Skip non-normative norms (`Inhaltsübersicht`, `Eingangsformel`, empty `enbez`, "(weggefallen)").
- Keep `Abs.` structure in text as `(1) … (2) …`; do not split a § across chunks (a few §§ are long:
  if > 2 000 tokens, split by `Absatz`; tokens are counted by `ingest.text.count_tokens` (regex `\w+|[^\w\s]`, defined here and reused by T2.3/T2.4) and keep the same `citation_key` + `section="Abs. N"`).
- `version_date`: parse from `<standangabe>`/`builddate` attribute; None if absent.
- `doc_id`: `gii-<jurabk lower>-<§ number>` e.g. `gii-bgb-622`, `gii-bgb-626a`; tenant is assigned
  later (T2.5), so loaders set `tenant="unassigned"`.
- Use `lxml` with `resolve_entities=False, no_network=True` (XXE-safe).

## Interfaces (must match `interfaces.md` exactly)

```python
# pruefstand.core.models.corpus (consumed, defined in T1.1)
class Document(BaseModel): doc_id: DocId; tenant: TenantId; source: str; lang: Lang; title: str
                           law_abbrev: str | None; version_date: date | None; text: str
                           license: str; url: str | None; metadata: dict[str, str] = {}
class Chunk(BaseModel):    chunk_id: ChunkId; doc_id: DocId; tenant: TenantId; lang: Lang; text: str
                           citation_key: str | None; section: str | None; parallel_id: str | None
                           version_date: date | None; license: str; source: str; is_attack: bool = False
# pruefstand.core.protocols (consumed); implemented here as GiiXmlLoader, ParagraphChunker
class Loader(Protocol):  def load(self, raw_dir: Path) -> Iterator[Document]: ...
class Chunker(Protocol): def chunk(self, doc: Document) -> list[Chunk]: ...
```
