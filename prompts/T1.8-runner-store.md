## Goal

`Runner.run(...)` executes all cases concurrently against a `TargetAdapter`, retries transient
failures, computes deterministic metrics, stops cleanly on budget exhaustion, and returns
`RunResults`; `ArtifactStore` writes and reads the run directory losslessly.

## Context

`Runner` returns a `RunResults` whose `manifest` contains only what the runner knows (counts, cost,
duration, `complete`, `stop_reason`, target fingerprint, seed); dataset/config fields are filled by
the pipeline (T1.10) via `manifest.model_copy(update=...)`. Judges are `None` in v1 (judged metrics
come in T5.2b) but the hard-fail-skips-judges ordering from interfaces §8 is implemented now.

`judges` is typed with the structural `core.protocols.JudgePoolLike` (`for_metric(metric: str) ->
JudgeLike`, `JudgeLike.score(task: JudgeTask) -> JudgeVerdict`, async). This task adds those two
protocols and `core/models/judge.py` (`JudgeTask`, `JudgeVerdict`, verbatim from interfaces §6) so
the runner never imports `judges`; T5.2a implements them. The hard-fail list comes in as a
keyword-only constructor argument `hard_fail: tuple[str, ...]` (default = `GatePolicy` default) —
a pre-approved addition. The budget is charged **only** by LLM calls (judged metrics, through
`LLMClient`); in v1 nothing charges it, so the budget test injects a stub judged metric that charges.
The runner owns **only** the target-response cache (optional `KVCache`, namespace `target`; `DiskKVCache` is created here in `store/kv.py`, decision D75 in docs/decisions.md; T5.1 uses it for the `llm` namespace; T6.1 adds `LayeredKVCache` and the PR overlay). Judge/LLM caching lives only inside `LLMClient` — the runner never caches judge results. `RunArtifacts` is `{results: RunResults, root: Path}` (core.models.run).

## Subtasks

- [ ] S1 `runner/runner.py`: `asyncio.Semaphore(cfg.concurrency)`; per case: build `TargetRequest(request_id=uuid4().hex)`; cache lookup (key interfaces §8); `asyncio.wait_for(adapter.query, cfg.timeout_s)`, except for cases of split **`robust_pr`** (R11 D218/D222, Y4.1): those call `adapter.retrieve` (no generation), are recorded with `CaseRecord.mode="retrieve"` and the response stored as `TargetResponse(answer="", chunks=…)`, and count `counts["retrieve"]`; `retrieve()` returning `None` (target without `/v1/retrieve`) falls back to `query` for that case and counts `counts["retrieve_fallback"]`; metrics that need an answer get `status="not_applicable"` for `mode="retrieve"` records (never 0); retry only `TargetError(transient=True)`/timeouts up to `max_retries` with exponential backoff `backoff_s * 2**attempt` (jitter from seeded rng); record `CaseRecord` (error text ≤ 500 chars, no secrets).
- [ ] S2 Metrics: `evaluate_deterministic` + `LatencyMetric.from_record` + `ErrorRateMetric.from_record`; a case whose request finally failed gets `status=error` for every other applicable metric and `error_rate = 1.0` (the gate fills worst values, T1.7).
- [ ] S3 Hard-fail ordering: if any metric in `hard_fail` fired (value 1), the case keeps its deterministic values and judges are **not** called for it (v1: judges are None; test the branch with a spy `JudgePoolLike` stub).
- [ ] S3b `core/models/judge.py` (`JudgeTask`, `JudgeVerdict`) and `JudgeLike`/`JudgePoolLike`/`JudgedMetric` (verbatim from interfaces §5) in `core/protocols.py`. Runner v1 judge hook: when `judges` is not `None` and no hard fail fired, `await m.acompute(case, resp, judges)` for every registry metric with `kind == JUDGED` (the default registry has none yet; the budget and spy tests register a test-only judged metric). T5.2b extends this hook (robust_pr skip, base-before-variant order).
- [ ] S3c **Judge failures** (round-8 W3.9). In the judge hook, `LLMError` (after the client's retries) or `PolicyViolation` from a judged metric → that metric gets `MetricValue(status="error", value=None, details={"error": <exception class name>})`, the case continues, and `counts["judge_error"]` is incremented. **The runner is the single owner of judge-failure and quota accounting** (round 9 D9-07; T5.1 only raises, never recounts). Exceptions to that: (a) `QuotaExhausted` (subclass of `LLMError`, interfaces §2; raised by the client when the free quota is exhausted, T5.1; W1.4): judging stops for the rest of the run, remaining judged values are `not_applicable` with `details={"reason": "judge_quota"}`, `counts["judge_skipped"]` counts them, and they do not count as judge errors; (b) **request cap without a race** (round 9 X4.5, D9-06): before every judge call the runner does `await budget.reserve(2)` (the call + one possible `complete_json` repair) and after it `await budget.release(2 − used)`; a failed reservation (the cap is `budget.max_requests_per_run`, D143; `RunnerConfig` has no judge field) → that value `not_applicable` with reason `judge_cap`, `counts["judge_skipped"] += 1`, no call. So `BudgetExceeded` never comes from the request cap, even at concurrency 8 (USD/token caps still raise). After the run: if `judge_error / judged_cases > 0.05` → `manifest.judge_degraded = True` (the gate then treats judged metrics as informational, T1.7 5a). `BudgetExceeded` is **not** caught here; it propagates to S4. The runner also sums `details["refusal_flag_mismatch"]` into `counts["refusal_flag_mismatch"]` (W3.5).
- [ ] S4 Budget: catch `BudgetExceeded` → cancel pending tasks, `complete=False`, `stop_reason="budget_exceeded"`; KeyboardInterrupt/`CancelledError` → `"aborted"` (`infra_error` stays `None`). Results keep finished cases. `ArtifactStore.mark_aborted(run, infra_error)` (R11 D245, used only by the T6.2a executor after an infra failure) rewrites `run.json` atomically with `complete=False`, `stop_reason="aborted"`, `infra_error`.
- [ ] S5 Result order = input case order regardless of completion order.
- [ ] S6a `store/kv.py` `DiskKVCache(directory: Path, namespace: Literal["target", "llm"], *, read_only: bool = False)` implementing `KVCache` on `diskcache.Cache(directory / namespace)`: `get` returns `bytes | None`; `set` raises `StoreError` when `read_only` (PR jobs); keys are opaque strings (callers pass `stable_hash` output); values stored as bytes; `close()` + context manager. Add `diskcache` to runtime deps (decisions.md line).
- [ ] S6b (round 12 N6.4, D267; pre-approved, interfaces §7) `ArtifactStore.add_counts(run_id_or_path, counts)`: merges the given keys into `RunManifest.counts` of `run.json` atomically (tmp + rename, re-validated with `RunManifest.model_validate`); only `model_reloads` and `upstream_errors` are accepted (any other key → `StoreError`); existing counts kept; every other file untouched. Called only by the executor (T6.2a) with the `llm-proxy` `/health` deltas.
- [ ] S6c (round 12 N1.2, D249) judged subset: `Runner.run(..., judged_subset: bool = False)` (keyword-only, default keeps today's behaviour; called by T1.10's `run_eval`): when true, judged metrics run only on cases with `TestCase.judged_subset`; on every other case each judged metric gets `status="not_applicable"`, `details["reason"] == "not_in_judged_subset"`, never counted as `judge_skipped`. **Round 13 P3.4:** the subset also limits **generation**: a `core` answerable case (factual, multi_hop, comparison, cross_lingual) outside the subset is routed like a `robust_pr` case (`/v1/retrieve`, `CaseRecord.mode = "retrieve"`, retrieval metrics only, answer metrics `not_applicable` with reason `not_in_judged_subset`); every other case (smoke, `unanswerable`, `injection` and other deterministic security cases) is generated and scored by every deterministic metric. If interfaces §8 does not yet show the keyword, add it there in this PR (pre-approved by N1.2).
- [ ] S6 `store/artifacts.py` `ArtifactStore(root)`: `write_run(RunArtifacts(results, root=<store root>/<run_id>))` → writes into `run.root` (must be under the store root, else `StoreError`) and returns it: `run.json` (indent 2, sorted keys), `results.parquet` (columns interfaces §8, polars, zstd), `responses.jsonl`, `llm_calls.parquet` (if recorder given); atomic writes (tmp dir + rename); `read_run` returns `RunArtifacts` whose `.results` equals what was written. Run id = `<UTC yyyymmddTHHMMSS>-<6 hex>`.

## Interfaces (must match `interfaces.md` exactly)

```python
class Runner:   # __init__ carries `# noqa: PLR0913` (X4.1 allowed long signatures); runner/runner.py has the per-file PLR0917 ignore (D9-04)
    def __init__(self, adapter: TargetAdapter, metrics: MetricRegistry, judges: JudgePoolLike | None,
                 cache: KVCache | None, budget: Budget, cfg: RunnerConfig,
                 *, hard_fail: tuple[str, ...] = ("canary_leak", "tenant_leak", "system_prompt_leak")) -> None
    async def run(self, cases: Sequence[TestCase], *, target_fingerprint: str, seed: int,
                  judged_subset: bool = False) -> RunResults          # round 12 N1.2 (S6c)
class ArtifactStore:
    def __init__(self, root: Path) -> None
    def write_run(self, run: RunArtifacts) -> Path
    def read_run(self, run_id_or_path: str | Path) -> RunArtifacts
    def mark_aborted(self, run_id_or_path: str | Path, infra_error: str) -> None   # R11 D245
    def add_counts(self, run_id_or_path: str | Path, counts: Mapping[str, int]) -> None   # R12 N6.4 (D267)
```
