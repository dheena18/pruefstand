## Goal

`OldpLoader` reads the pinned 1k court-decision sample from `data/raw/hf/oldp_decisions/` (written by
T2.1 with `snapshot_download(local_dir=…)`) and
`DecisionSectionChunker` splits each decision into `Tenor`, `Tatbestand`, `Entscheidungsgründe`
(and `Leitsatz` when present), with ODbL license metadata on every chunk.

## Context

- Records have HTML/plain `content` with headings like `Tenor`, `Tatbestand`, `Entscheidungsgründe`,
  `Gründe`, `I.`, `II.`; court, date, file number (`Aktenzeichen`, e.g. `2 AZR 123/24`), ECLI.
- Map `Gründe` → `Entscheidungsgründe`. Decisions without detectable sections → FixedTokenChunker
  (512 tokens, 64 overlap) with `section=None` (count them in stats).
- `Entscheidungsgründe` are long → sub-split by Randnummer or by ≤ 512-token windows; keep `section`.
- `doc_id`: `oldp-<id>`; `title`: `"<court> <date> <Aktenzeichen>"`; `license="ODbL-1.0"`;
  `metadata`: court, court_level, jurisdiction (`Arbeitsgericht`, `Zivilgericht`, …), ecli, file_number.
- Read the parquet/JSONL files under `data/raw/hf/oldp_decisions/` directly (pyarrow / `datasets`
  with `data_files=`); never the HF cache, never the network (`HF_DATASETS_OFFLINE=1` in tests).
  The citation graph comes from `data/raw/hf/oldp_citation_graph/`.
