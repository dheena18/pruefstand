## Goal

Four meaning-preserving rewrites — `compound_split`, `register`, `gender`, `colloquial` — use a
rules-first, LLM-second approach (rules where reliable, LLM via `LLMClient` role `PERTURB` with
versioned prompts otherwise), each followed by an automatic **validity check** that the rewrite
kept the meaning and actually applied the transformation.

## Context

- `compound_split` (hybrid): rule step finds compounds ≥ 10 chars using a splitter (same library
  family as T3.3 is allowed, but **own code in `pruefstand`**; no import from `rag_demo`), LLM
  rewrites to an analytic phrase: "Kündigungsschutzgesetz" → "Gesetz zum Schutz vor Kündigungen";
  "Arbeitszeitgesetz" → "Gesetz über die Arbeitszeit"; "Rahmenvertrag" → keep if no natural paraphrase.
- `register` (rules first): Sie → du ("Können Sie mir sagen, …" → "Kannst du mir sagen, …"),
  verb agreement via LLM if the rule cannot conjugate; also du → Sie for inputs already informal.
- `gender`: "Mitarbeiter" → "Mitarbeiter*innen" or "Mitarbeitende" (seeded choice of style:
  Gendersternchen, Doppelpunkt "Mitarbeiter:innen", Partizip "Mitarbeitende", Paarform
  "Mitarbeiterinnen und Mitarbeiter"); rule table for ≥ 40 frequent nouns, LLM for the rest + articles.
- `colloquial` (LLM only): "Unter welchen Voraussetzungen ist eine ordentliche Kündigung durch den
  Arbeitgeber zulässig?" → "Wann darf mein Chef mich rauswerfen?"; must not add facts or remove the
  legal question.
- Validity check (`perturb/validate.py`): (1) transformation present (rule-specific regex, e.g. no
  "Sie" left for register→du; `*innen|:innen|ende\b|innen und` for gender); (2) meaning preserved:
  LLM equivalence check prompt `perturb_equivalence_de_v1.txt` → `{"reason", "score": 0|1}` with a
  model family different from the rewriting model; (3) no new numbers/§ introduced. Failed → `changed=False`.
- **Serving (round 10 Z3; R11 Y3):** all A40 models are `ollama/<tag>` ids called from the VM through the tunnels via
  `LLMClient` (LiteLLM `ollama_chat`, native `/api/chat`, never `/v1`) with exactly the catalogue `options` of the
  model (D219–D221). The `large` rewriter (llama 70B-class `Q4_K_M`) runs only in the weekend `datagen` mode
  (`make gpu-large-up`: the one Ollama server, llama split over both GPUs, on `OLLAMA_GPU0_URL`, ADR-0018; `switch-mode.sh datagen` creates
  `/var/lib/pruefstand/MAINTENANCE` itself and `make gpu-up` removes it, D230; nobody touches the file by hand, X3.12),
  in which **no judge is served**. Pass 1 checks that the file exists and the `large` tag is resident
  (`/api/ps`), else exit 2 "run make gpu-large-up first"; pass 2 refuses while the file exists. Therefore the run has **two passes**: (1) datagen weekend: rewrite every case (LLM cache on); (2) day
  mode: the equivalence check with the `judge` entry on `OLLAMA_GPU1_URL`, while the rewrites come from the cache
  (no 70B call). The CLI takes `--pass rewrite|validate|both` (`both` only when both endpoints answer, e.g. for
  cassette recording).
- Models (from `infra/gpu/models.yaml`, T3.1b): rewriting = the `large` entry; equivalence check =
  the `judge` entry. If both have the same family, use a GitHub Models free-tier model of another family for the
  equivalence check (public questions only; the `LLMClient` external-provider guard blocks private
  docs and canaries); the validator raises `ConfigError` on equal families. A 10 % seeded sample of
  rewrites is also cross-checked with a GitHub Models model and logged for T4.7b review. No paid APIs.
- All prompts: `perturb/prompts/<name>_de_v1.txt`; temperature 0; LLM responses cached via `LLMClient`.

## Interfaces (must match `interfaces.md` exactly)

```python
class LLMPerturbation(Perturbation, Protocol):       # pruefstand.core.protocols
    async def aapply(self, text: str, llm: LLMClientLike, rng: np.random.Generator) -> PerturbResult: ...
    # typed with core.protocols.LLMClientLike (core cannot import llm); pass an LLMClient at runtime
async def perturb_case_async(case: TestCase, p: LLMPerturbation, llm: LLMClient, rng: np.random.Generator) -> TestCase | None
```
