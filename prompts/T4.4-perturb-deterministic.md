## Goal

Seven rule-based perturbations — `umlaut_translit`, `eszett`, `numbers`, `dates`,
`citation_style`, `abbreviations`, `typos` — each a small module implementing
`core.protocols.Perturbation`, registered by stable name, unit-tested with fixed input → output
pairs, and `perturb_case` turns a base `TestCase` into a perturbed one (or `None` if unchanged).

## Context

- One file per perturbation in `perturb/`; a registry `perturb/registry.py` maps name → instance.
- Each perturbation changes only the **question**; gold fields stay; `perturb_case` sets
  `id = f"{case.id}~{p.name}"`, `base_id = case.base_id`, `cluster_id = case.cluster_id`,
  `perturbation = p.name`, keeps split.
- Rules:
  - `umlaut_translit`: ä→ae, ö→oe, ü→ue, Ä→Ae, Ö→Oe, Ü→Ue (keep "§").
  - `eszett`: ß→ss (and ẞ→SS).
  - `numbers`: German format → international: "1.000,50 €" → "1000.50 EUR", "13,7 %" → "13.7 %";
    integers < 1000 unchanged; currency symbol € → "EUR".
  - `dates`: "03.10.2026" → "3. Oktober 2026"; "1.1.2025" → "1. Januar 2025"; leave "§ 3" untouched; invalid dates unchanged.
  - `citation_style`: "§ 622 BGB" → "Paragraph 622 des Bürgerlichen Gesetzbuchs"; "§ 1 KSchG" →
    "Paragraph 1 des Kündigungsschutzgesetzes"; "Art. 6 DSGVO" → "Artikel 6 der Datenschutz-Grundverordnung";
    "§ 622 Abs. 2 BGB" → "Paragraph 622 Absatz 2 des Bürgerlichen Gesetzbuchs". Long names and
    genitive forms are read **only** from `core/data/law_aliases.yaml` (single source, T1.5a); do not
    add a second law-name map. If a genitive form is missing there, add the row to that YAML (with a
    row in `tests/unit/core/test_citations.py`).
  - `abbreviations`: "Abs." → "Absatz", "Nr." → "Nummer", "ggf." → "gegebenenfalls", "i.V.m." →
    "in Verbindung mit", "z. B."/"z.B." → "zum Beispiel", "bzw." → "beziehungsweise".
  - `typos`: seeded, 1 edit per question in a word ≥ 6 letters (deletion/transposition/adjacent-key
    substitution on a QWERTZ map); "Kündigungsfrist" → e.g. "Kündigunsfrist". Never touches numbers, § or law abbreviations.
- `PerturbResult.changed=False` when no rule applied → `perturb_case` returns `None`.

## Interfaces (must match `interfaces.md` exactly)

```python
class PerturbResult(BaseModel): text: str; changed: bool; notes: str = ""
class Perturbation(Protocol):                      # pruefstand.core.protocols
    name: str; version: str; uses_llm: bool
    def apply(self, text: str, rng: np.random.Generator) -> PerturbResult: ...       # deterministic ones
def perturb_case(case: TestCase, p: Perturbation, rng: np.random.Generator) -> TestCase | None   # None if unchanged
```
