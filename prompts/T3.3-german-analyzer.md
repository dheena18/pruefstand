## Goal

A deterministic German analyzer turns text into search tokens (NFC, lowercase, optional ß/umlaut
folding, abbreviation expansion, Snowball German stemming, optional compound splitting) and a
`SparseEncoder` maps tokens to a hashed sparse vector with BM25-style term-frequency weights, so
Qdrant can apply IDF. `compound_split` is one `rag.yaml` switch (mutation M4 turns it off).

## Context

**This task extends rag-demo v0 (T1.13)**: the module already exists in minimal form and is used by tier-1 CI. Upgrade it in place, keep every bug switch from T1.13 working (their tests must stay green) and keep the CPU `live` profile working. No new parallel module, no stub/simulated classes (ADR-0008); tests use the real services (Testcontainers Qdrant, TEI CPU, llama.cpp from compose `live`) or cassettes recorded from them.

- Pipeline: NFC → lowercase → (optional) fold `ß→ss`, `ä→ae`, `ö→oe`, `ü→ue` **on both index and
  query side** (`fold_umlauts` config, default true, so "Gebühren" and "Gebuehren" match) →
  tokenise (keep `§`, numbers like `622`, `626a`) → stopwords (German Snowball list) → abbreviation
  map (`abs.`→`absatz`, `nr.`→`nummer`, `ggf.`→`gegebenenfalls`, `i.v.m.`→`in verbindung mit`,
  `bgb`→ keep, plus expanded `bürgerliches gesetzbuch`? **no**: expansion only for function
  abbreviations; law abbreviations stay) → compound split (emit the original token **and** its
  parts) → stem.
- Compound splitter: dictionary/statistics-based, deterministic, offline. Candidates: `charsplit`
  (n-gram probabilities, MIT) or a small own splitter on a word-frequency list; choose, add to
  decisions log with license. Split only tokens ≥ 10 chars; handle Fugen-s/-es/-n
  ("Kündigungs|schutz|gesetz").
- Sparse encoding: token id = `xxhash64(token) mod 2^31` (stable across processes; Python `hash()`
  is forbidden), weight = BM25 TF saturation `tf*(k1+1)/(tf+k1*(1-b+b*dl/avgdl))` with k1=1.2,
  b=0.75; `avgdl` stored in the index metadata. IDF comes from Qdrant `modifier=idf`.

## Interfaces (must match `interfaces.md` exactly)

```python
class GermanAnalyzer:  def __init__(self, compound_split: bool, stemmer: Literal["snowball_de", "none"], fold_umlauts: bool = True) -> None
                       # fold_umlauts: ä->ae, ö->oe, ü->ue, ß->ss so "Gebühren" and "Gebuehren" match
                       def tokens(self, text: str) -> list[str]
class SparseEncoder:   def encode(self, tokens: list[str]) -> SparseVector         # hashed vocab + BM25 term weights; IDF in Qdrant
```
