## Goal

The `pruefstand.core` package with the shared types every early task needs, a variadic
`stable_hash`, the **only** fingerprint and corpus-version functions, structured logging, the error
hierarchy, the first protocols, and `export_schemas()` writing JSON Schemas to `schemas/`.

- [ ] S5 `core/hashing.py` `stable_hash(*parts: object) -> str`: canonical JSON of the **list** of parts, then `sha256(...).hexdigest()[:16]`. JSON settings: `sort_keys=True`, `separators=(",", ":")`, `ensure_ascii=False`. Encoding rules:
  - Pydantic models via `model_dump(mode="json")`
  - tuples become lists; `Path` becomes `str`; `datetime`/`date` become ISO strings
  - `bytes` becomes `{"__bytes__": "<hex>"}`
  - anything else raises `TypeError`

  No Unicode normalisation (document this in the docstring).
- [ ] S6 `core/fingerprint.py` (pure, interfaces §17):
  - `corpus_version(manifest: CorpusManifest, date_tag: str) -> str` returns `f"{date_tag}.{h[:8]}"` with `h = stable_hash(sorted(manifest.sources.items()), sorted(manifest.tenants.items()), sorted(manifest.sha256.items()))`. The manifest's own `corpus_version` and `created_at` fields are **excluded** (no circularity, no clock). `date_tag` must match `^\d{4}-\d{2}-\d{2}$`, else `ValueError`.
  - `target_fingerprint(info: TargetInfo | None, *, url: str, run_id: str) -> str` returns `stable_hash(info.image_digest or info.git_sha, info.config_hash, info.corpus_version, sorted(info.models.items()), sorted(info.serving.items()))`; for opaque targets (`info is None`) it returns `stable_hash(url, run_id)`.
  - `eval_fingerprint(*, dataset_name: str, dataset_version: str, splits: Sequence[Split], judge_models: Mapping[str, str], judge_prompt_versions: Mapping[str, str], judge_serving: Mapping[str, str], judge_epoch: int, metric_versions: Mapping[str, str], corpus_version: str) -> str` (splits sorted by value; mappings sorted by key). The signature exceeds `max-args`; it carries `# noqa: PLR0913` and is on the coding-standards §1.1 "allowed long signatures" list (X4.1).
- [ ] S7 `core/errors.py`: the hierarchy exactly as interfaces §2, incl. `PromptError`, `CorpusMismatch` and `QuotaExhausted(LLMError)` (D9-07). `TargetError` takes keyword `transient: bool = False`.
- [ ] S8 `core/logging.py`: `get_logger(name)` + `configure_logging(json: bool, level: str)`, plus a structlog processor that redacts keys matching `(?i)token|key|secret|password|authorization`, and a second processor that redacts **values** matching `(sk-|hf_|gh[pousr]_)[A-Za-z0-9_]{8,}` inside any string, including exception messages (A8-48).
- [ ] S9 `core/schema.py` `export_schemas(out: Path) -> list[Path]` with a small registry (`register_schema(name, model)`), so later tasks add one line each. Now it registers `testcase`, `chunk`, `corpus_manifest`, `run_manifest`, `canary_registry`. Output is `<name>.schema.json` with sorted keys and a trailing newline. Commit `schemas/` (keep `schemas/.gitkeep` from T0.1).
