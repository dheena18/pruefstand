## Goal

A reproducible benchmark, run **through Ollama** (one server for both GPUs, ADR-0018) over the VM's tunnel, picks the exact generator, the
one judge (PR and nightly, ADR-0019), embedding models and reranker by evidence (German quality, JSON
validity, throughput at `OLLAMA_NUM_PARALLEL=4`, VRAM, first-load time from the cluster disk, disk size), and measures the
numbers that set the PR (≤ 90 min) and nightly (≤ 8 h inside the 22:00–06:00 Europe/Berlin window, D223)
budgets, **including the VM-CPU reranker lane** (Y4.2, D222). Winners are pinned by **tag + manifest digest
+ fixed `options`** in `infra/gpu/models.yaml` (`provisional: false`) and `docs/decisions.md`.
