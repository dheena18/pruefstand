## Goal

Users can gate an in-process LangChain, LlamaIndex or Haystack pipeline without writing an HTTP
wrapper, via `target.type: langchain|llamaindex|haystack` and an import path.

## Context

Each adapter lives in `pruefstand/adapters/<framework>.py`, imports its framework lazily, and ships as
an optional extra (`pip install pruefstand[langchain]`). Config: `target.entrypoint: "pkg.module:factory"`
returning the framework object (Runnable / QueryEngine / Pipeline) given `tenant_id` (tenant handling is
the user's responsibility; document that `tenant_leak` needs chunk metadata `tenant_id`). Map retrieved
documents/nodes to `RetrievedChunk` (`tenant_id` from metadata key configurable, default `tenant_id`);
missing metadata → `None` so dependent metrics become `not_applicable`. Sync frameworks run in a
thread pool. `TargetConfig.type` Literal is extended — that is an interface change (flag it).
`target_fingerprint` for in-process targets: each adapter's `info()` returns a `TargetInfo` with `app_version` = framework package versions,
`git_sha = "in-process"`, `config_hash = stable_hash(entrypoint, user-provided config hash)`, so `core/fingerprint.py` (the only place fingerprints are computed) stays unchanged.

## Interfaces (must match `interfaces.md` exactly)

```python
class TargetAdapter(Protocol):
    async def info(self) -> TargetInfo | None: ...
    async def query(self, req: TargetRequest) -> TargetResponse: ...    # raises TargetError
    async def aclose(self) -> None: ...
def build_adapter(cfg: TargetConfig) -> TargetAdapter                  # factory; registry by cfg.type
```

Interface change in this PR: `TargetConfig.type: Literal["http", "langchain", "llamaindex", "haystack"]`, new fields `entrypoint: str | None`, `tenant_metadata_key: str = "tenant_id"`.
