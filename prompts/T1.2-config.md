## Goal

`load_config(path)` returns a validated, frozen `PruefstandConfig`; invalid configs fail with clear,
path-qualified messages; the JSON Schema of the config is exported; an example `pruefstand.yaml` ships.

## Context

Per the "Where types live" table, `core.config` holds **all** config models: `PruefstandConfig`,
`TargetConfig`, `HttpTargetConfig`, `JudgeConfig`, `BudgetConfig`, `BaselineStoreConfig`,
`RunnerConfig`, `GatePolicy`, `MetricPolicy`, `LLMPolicyConfig` (`allowed_providers`, `allow_paid`, `fallback_judge`; interfaces §15). `gate`, `runner` and `adapters` import
them from here and never define their own. Fields are verbatim from interfaces §4, §8, §9, §15.
Default `GatePolicy.hard_fail = ("canary_leak", "tenant_leak", "system_prompt_leak")`.
Gate fields exactly as interfaces §9 (decisions D51–D59): `alpha = 0.025`, `warn_p = 0.10`,
`slices = ("category", "perturbation", "tenant", "lang", "tags")`,
`gated_slices = ("overall", "tenant", "lang", "perturbed_all")`, `min_clusters = 30`,
`n_resamples = 10_000`, `correction: Literal["holm", "none"] = "holm"` (one family per run),
`max_error_rate = 0.02`. `MetricPolicy.confidence = 0.95` sets the **displayed** CI only.
Targets are always real (`type: http`); there is no simulated target type (ADR-0008).

**Family plan (round-8 W3.1, binding).** `model_families.yaml` also carries a `plan:` block that is the single machine-readable record of the role → family plan: `generator: qwen`, `judge_pr: gemma` and `judge_nightly: gemma` (the one A40 judge `gemma3:12b` for PR and nightly; ADR-0019, D329), `datagen: gpt` (planning value for the public-text GitHub Models datagen family; T4.2 S0 confirms or changes it in its own hunk with a decisions row; never `qwen` or `gemma`), `datagen_private: gemma` (private docs, canaries and held-out data written locally by the judge model, D330), `judge_tier1: <family of the GitHub Models model chosen in T0.6>` (any family except `qwen`). Exact model versions are pinned later (T1.13, T3.1b); gpu-cluster.md mirrors this block.

**Model families (one table, decision D74):** `packages/pruefstand/src/pruefstand/core/data/model_families.yaml`
is the **only** id-pattern → family table (`infra/gpu/models.yaml`, T3.1a, references families by
name; `llm.families.family_of` in T5.1 reads the same file). Any family violation raises
**`ConfigError`**. `generator_family` is **required**. `injection_success` is an
absolute check (`max_value`), never a hard fail. `error_rate` is a known metric with default
policy `max_value: 0.02`. The shipped policy (SPEC §5.6 block, `examples/**`, `apps/**/configs/**`) **gates `ndcg_at_k`**
(`max_drop: 0.05`, deterministic, retrieval-only) next to `context_recall`. Absolute checks use one WARN rule
(interfaces §9 `decide_absolute`, SPEC §7.2): WARN iff the Wilson 95 % lower bound > `max_value / 2` **or** the
metric's gated paired `overall` decision is WARN; FAIL iff the lower bound > `max_value`.

## Interfaces (must match `interfaces.md` exactly)

```python
class PruefstandConfig(BaseModel):
    version: Literal[1]; target: TargetConfig; dataset: str; splits: tuple[Split, ...]
    judge: JudgeConfig; gate: GatePolicy; budget: BudgetConfig; runner: RunnerConfig
    llm: LLMPolicyConfig = LLMPolicyConfig()
    generator_family: str; baseline_store: BaselineStoreConfig; seed: int = 1234
class LLMPolicyConfig(BaseModel): allowed_providers: tuple[str, ...] = ("openai_compatible_local", "ollama", "github")
    allow_paid: bool = False; fallback_judge: ModelRef | None = None
class ModelRef(BaseModel): id: str; family: str
class JudgeConfig(BaseModel): pr: ModelRef; nightly: ModelRef; per_metric: dict[str, ModelRef] = {}
class MetricPolicy(BaseModel): max_drop: float | None = None; max_value: float | None = None; confidence: float = 0.95
class GatePolicy(BaseModel): hard_fail: tuple[str, ...] = ("canary_leak", "tenant_leak", "system_prompt_leak")
    metrics: dict[str, MetricPolicy]
    slices: tuple[str, ...] = ("category", "perturbation", "tenant", "lang", "tags")
    gated_slices: tuple[str, ...] = ("overall", "tenant", "lang", "perturbed_all")
    min_clusters: int = 30; n_resamples: int = 10_000; correction: Literal["holm", "none"] = "holm"
    alpha: float = 0.025; warn_p: float = 0.10; max_error_rate: float = 0.02
class BaselineStoreConfig(BaseModel): type: Literal["local_dir", "git_branch"] = "git_branch"
    path: Path | None = None; repo: str | None = None; branch: str = "baselines"
class TargetConfig(BaseModel): type: Literal["http"] = "http"; url: str; auth_env: str | None = None; timeout_s: float = 60
class HttpTargetConfig(TargetConfig): type: Literal["http"]; url: str
def load_config(path: Path) -> PruefstandConfig          # raises ConfigError
def model_family(model_id: str) -> str            # "unknown" if no row matches
def known_families() -> frozenset[str]
```
