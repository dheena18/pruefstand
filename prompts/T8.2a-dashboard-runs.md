## Goal

Static pages under `/[locale]/` (`de` default, `en`): the runs list, the run summary (tier-2 and tier-1
variants), the licences page and the 404 / error content, plus the shared components and the full de/en
strings every later page uses — layout, states and copy exactly as `docs/design/ui-spec.md`.

## Context

- Routes per ui-spec §2.1: `/[locale]/` and `/[locale]/runs/[id]/` (`generateStaticParams` in the
  summary `page.tsx` = every run of `runs/index.json`; an empty index → the `_empty` placeholder of T8.1,
  Y7.2, `dynamicParams = false`; a shared `runs/[id]/layout.tsx`, if added for `RunSubNav`, exports **no**
  `generateStaticParams`, so T8.2b's Diff/Slices/Cases pages generate their own subsets, UI12-08),
  `/[locale]/licences/`; `NotFoundView` content for the site 404 and `[locale]/not-found.tsx`;
  `error.tsx` content. Root redirect, file tree and shell are T8.1's.
- Query-driven pages (ui-spec §6, UI11-09): the runs list's static HTML is the default view (no
  filters, page 1, created desc) rendered from build-time data as the `<Suspense>` fallback around the
  `useSearchParams` reader; the client applies the query after hydration and sets
  `data-hydrated="true"` on `<main>`.
- Data is validated at build time (ui-spec §2.4); these pages have no "bad data" state.
- **Runs list (ui-spec §4.1):** `runs/index.json` (`DashboardRunIndex`) read at build time and embedded (no runtime request); columns Status,
  Ref, PR, Created, Tier (`stack`), Workload (`workload`, then `· b<k>` when `block` is set and
  `· subset` when `judged_subset`, keys `runs.block_short` / `runs.judged_subset_short`; UI13-19),
  Cases, Duration, Cost, Flags (text: incomplete, judge skipped,
  judge fallback, judge degraded, judge drift); status cell `no_baseline == true` → `⊘ NO BASELINE`,
  `status == null` → NOT GATED, never PASS; filters (status values of ui-spec §4.1 incl. `no_baseline`
  and `not_gated`, matched against the **rendered status cell**: `no_baseline` first, then
  `not_gated`, else `status`, so `insufficient_data` excludes no-baseline runs, UI11-19), ref, tier,
  workload), sort and page **in the URL query** (UI-24); count in
  `aria-live`; `DataTable` responsive rule (table in a focusable scroll region ≥ 640 px, cards below,
  UI-23); states `L-POPULATED`, `L-EMPTY`, `L-FILTERED-EMPTY`. "Created" header has no zone; cells use
  the ui-spec §10.1 date format (UI9-13). Ref cell = ui-spec §2.2 ref label (UI9-14).
- **Run summary (ui-spec §4.2):** header block (status + blocking count + `TierBadge` + likely cause;
  meta `<dl>` with ref labels, tokens = prompt + completion, GPU-s only for `stack == "a40"`, workload
  with ` · block <k>` (`summary.block`) when `run.json.block` is set, and the judged heading followed by
  `summary.judged_subset` "judged subset (150 cases)" when `run.json.judged_subset` (UI13-19); baseline
  line `–` when `baseline_run_id` is null, the linked ref label when the baseline is in the index,
  else `baseline_run_id` in mono without link (UI11-08); `judges:` only when `judge_models` is not
  empty, so tier 1 shows `judge mode github` only (UI11-14)), banner
  zone with every banner of the §4.2 table in its order (`S-PARTIAL`, `S-NOT-GATED`, `S-NO-BASELINE`,
  `S-JUDGE-SKIPPED`, `S-JUDGE-FALLBACK`, `S-JUDGE-DEGRADED`, `S-JUDGE-DRIFT`, `S-UNSUPPORTED`,
  `S-BASELINE-MISSING` — the last only when `baseline_run_id` is not null), `RunSubNav` (Diff/Slices
  disabled with `subnav.not_gated` without `gate.json`, and with `subnav.nothing_compared` when
  `no_baseline` (UI11-20); "Cases (n failing)" from shard 0 at build time, UI9-22; Cases disabled with
  `subnav.cases_not_published` for `S-CASES-PRUNED`), then the body.
- **`S-PARTIAL` reason and `infra_error` (UI12-16, owner: this task):** `banner.incomplete` `{reason}` =
  `stop_reason.<code>`, except `stop_reason == "aborted"` with `run.json.infra_error` set →
  `stop_reason.aborted_infra` ("aborted (infrastructure)"). The `infra_error` value is never rendered
  anywhere; only whether it is set is read. Published data carries only its kind (`sanitise_run`,
  T6.1, UI13-13), but the rule stays: never render it.
- **Judge drift banner (UI13-10):** `banner.judge_drift` is the D253 count text of ui-spec §10.4.1
  ("Judge drift detected (5 or more of 50 anchor verdicts changed); judged metrics are informational
  until the flag clears." / de "Judge-Drift erkannt (5 oder mehr von 50 Ankerurteilen geändert); …"),
  never the old 0.85 agreement wording.
- **`S-CASES-PRUNED` (N5.1, ui-spec §2.3, §4.2):** a run outside the newest 20 has no `cases/<id>/` and
  no `report.html`. Known at build time from the absence of `cases/<id>/0.json`: Cases sub-nav disabled
  "(cases not published)", no `ReportLink`, "Top failing cases" as plain ids followed by
  `summary.cases_not_published`, failing count not shown; `HardFailList` (tier-2 panel and tier-1
  findings) keeps rule, case id, metric and redacted evidence but renders **no** `[Open case →]` link
  (the case page does not exist; UI13-16).
  **Every `SliceDecision` goes to exactly one table by ui-spec §11.1 = interfaces §9** (Gated:
  `gated && informational_reason == null`; Informational: `informational_reason != null`; Notable: in
  `notable_slices` otherwise). `src/lib/tables.ts` has two pure functions mirroring T1.9's
  `report/tables.py`: `assignTable(decision, source)` and `assignBlock(decision, source, stack)` (blocks
  G, A/C, R, J, I, N); every summary section reads its rows through them:
  - `stack == "a40"` → tier-2 body §4.2.1: hard fails first; block G `overall` (Base, PR,
    Δ (95% CI), δ = `max_drop`, MDE, Status); block G other dimensions not passing; block A (Value,
    Max = `max_value`); block I with reason labels; notable line (block N, `notable == true`); "Not
    applicable" from `not_applicable_counts`; insufficient line from block G `INSUFFICIENT_DATA` rows
    with `n_clusters`; top failing cases linking to the static case pages.
  - `stack == "live"` → tier-1 body §4.2.2 (X5.6, X3.11): `Tier1Notice`; Checks table (hard-fail row +
    block C: `error_rate`, which decides and shows its status word); block R "Reported — does not decide at n = …" (reasons
    `tier1_deterministic_only`, `tier1_injection_reported` for `injection_success`,
    `applicable_clusters<30`; "Reported because" = reason label, no status word); block I for any other
    reason (e.g. `refusal_outside_nightly_full`, `judge_truncated`); block J (`tier1_judged`) with
    `judged_cases` and `{source}` = `judge_source.<judge_mode>` (UI11-14), or the skipped
    text when `judge_mode == "skipped"`.
  - `no_baseline == true` → `StatusBadge` `NO_BASELINE` (`⊘ NO BASELINE`, neutral tokens), alert banner,
    hard fails if present, no metric tables, never PASS styling (X5.5).
  - Blocking count = `len(hard_fails)` + FAIL rows of the Gated table (blocks G and A/C).
  - `ReportLink` to `${basePath}/data/runs/<id>/report.html` exactly when `status != null` **and** the run
    is case-published (ui-spec §4.9); open and Download are plain `<a href>` elements, never
    `next/link` (UI12-09).
- **Licences + footer (ui-spec §4.7, UI-07):** `/licences/` page from `src/content/licences.json`
  (T8.1's `gen_licences.mjs`); the footer attribution is on every page (T8.1 shell) — this task adds
  the page and the `content.spec`-ready markup.
- **i18n (ui-spec §10, W5.4):** locale from the route, `<html lang>` static; all strings in
  `src/i18n/{de,en}.json` incl. every ui-spec §10.4.1–§10.4.3 key (do not invent copy; a missing key is
  a ui-spec change in the same PR); metric labels, cause messages, hard-fail rule names and
  informational reasons come from `data/labels.json` (`LabelsDocument`, en) + `de.json` keys (UI-26);
  hard-fail rule names: en from `labels.json` `hard_fail_rules` (a code → en label dict, D273), de from
  `de.json` `rule.<code>`, so `/en` never shows a raw rule code (ui-spec §10.1, UI12-15);
  `banner.incomplete {reason}` = `stop_reason.<code>`; German data (evidence) wrapped in `lang="de"`
  also on `/en` pages; dates and numbers per ui-spec §10.1–§10.2.
- Status is never colour alone: icon + text + accessible name. No `style` attribute in server-rendered
  markup (ui-spec §7.4).
- "Try it" nav link only when `NEXT_PUBLIC_DEMO_API_URL` is set at build (UI-25).

## Interfaces (must match `interfaces.md` exactly)

```python
class SliceDecision(BaseModel):   metric: str; dimension: str; value: str; status: GateStatus; gated: bool
                                  notable: bool = False
                                  baseline_mean: float; candidate_mean: float; result: BootstrapResult | None
                                  p_adjusted: float | None; mde: float | None
                                  max_drop: float | None = None; max_value: float | None = None
                                  n_clusters: int | None = None; informational_reason: str | None = None
                                  # gated == False whenever informational_reason is set (interfaces §9)
class GateReport(BaseModel):      ...; baseline_run_id: RunId | None; not_applicable_counts: dict[str, int] = {}; no_baseline: bool = False
class RunIndexEntry(BaseModel):   run_id, created_at, git_ref, git_sha, pr_number, n_cases, duration_s, cost_usd, complete,
                                  stop_reason, stack, workload, judge_mode ("github"|"local"|"skipped"), judge_fallback,
                                  judge_degraded, judge_drift, status (None = no gate.json), no_baseline, baseline_run_id,
                                  block: int | None, judged_subset: bool   # R13 UI13-19, added by T8.1
class LabelsDocument(BaseModel):  schema_version; metrics; causes; hard_fail_rules: dict[str, str]; informational_reasons   # R12 D273
class RunManifest(BaseModel):     ...; complete: bool; stop_reason: Literal["completed", "budget_exceeded", "aborted"]
                                  infra_error: str | None = None   # R11 D245; set only with stop_reason="aborted"; never displayed
                                  block: int | None = None; judged_subset: bool = False   # R12 N1.3; shown per UI13-19
```

TS types come only from `src/types/generated/` (never hand-written duplicates).
