## Goal

A provider-agnostic `LLMClient` that talks to **real models from day 1** (llama.cpp server on CPU,
Ollama on the A40s (reached from the VM through SSH tunnels, round 10), GitHub Models free tier — all through LiteLLM), enforces budget and the free-only
provider policy, records every call, renders versioned prompt files strictly and parses JSON output.

## Context

There is **no simulated LLM** in this project (ADR-0008). Tests are of two kinds:

1. **Live tests** (`@pytest.mark.live`): call a real model. In CI they run against the llama.cpp
   container from compose profile `live` (T0.3) serving the small pinned **test model**
   `Qwen2.5-0.5B-Instruct-GGUF` `q4_k_m` (≈ 0.4 GB, Apache-2.0; verify license and pin the file
   SHA-256 in `infra/models/test-models.yaml`). Endpoint via `PRUEFSTAND_TEST_LLM_URL` (all env names: `docs/ops/secrets.md`)
   (default `http://localhost:8080/v1`). Assertions are about **structure and behaviour**
   (non-empty text, usage counts > 0, JSON parsable after `complete_json`, latency recorded), never
   about exact wording.
2. **Cassette tests** (default unit run, no network): replay HTTP exchanges that were **recorded from
   the real llama.cpp server** with `pytest-recording` (vcrpy) by `make cassettes`. Cassettes live in
   `packages/pruefstand/tests/cassettes/llm/`, each with a header comment `recorded: <date>, model:
   <id>, sha256: <gguf sha>`. They cover parsing, retries and error mapping deterministically.
   Every behaviour tested by a cassette is also tested live.

Per the "Where types live" table, `LLMRole`, `Message`, `LLMRequest`, `LLMResponse`, `PromptTemplate`
are defined in `core/models/llm.py`; `LLMBackend` and the structural `LLMClientLike` go in
`core/protocols.py`. This task adds all of them.

**`CassetteRecorder` is implemented here** (round-8 W4.6; interfaces §3 `CassetteRecorder(dir, mode)`). Two layers, both from real recordings:

- HTTP level (`pytest-recording`/vcrpy, above): retries, 503, error mapping, JSON-mode wire format inside `llm/`.
- Backend level, `llm/cassettes.py` `CassetteRecorder`: `mode="record"` wraps a real `LLMBackend` and writes each `(LLMRequest, LLMResponse)` pair as one JSON file `<dir>/<stable_hash(request)>.json` (no headers, no API keys: only the request/response models; `recorded_at`, `model_id` and the backend's `model_version` if reported in a header field of the file); `mode="replay"` is an `LLMBackend` that returns the stored response (with `cached=False`, original `usage`/`latency_ms`) for an identical request and raises `LLMError("cassette miss: <hash>", transient=False)` otherwise, never a made-up answer. Method `wrap(self, backend: LLMBackend | None) -> LLMBackend` (pre-approved addition; `backend` must be non-`None` in record mode → else `ValueError`). Later tasks (T4.2, T4.5, T5.2a, …) use it to replay real judge/datagen responses in unit tests without HTTP. Name and behaviour keep the "no stub or simulated LLM" rule: every cassette comes from a real model through `make cassettes`.

**Qwen3 thinking is off everywhere** (round-8 W1.2). When the model id contains `qwen3`, `LiteLLMBackend` sends `extra_body={"chat_template_kwargs": {"enable_thinking": false}}` (llama.cpp needs `--jinja`; for the A40 provider, which is Ollama since round 10, T5.1 adds `"think": false` on the native `/api/chat` call — never the `/v1` path or a `/no_think` marker, R11 D219; gpu-cluster.md §2.1) and strips a leading `<think>…</think>` block defensively. The strip function `strip_think(text) -> tuple[str, bool]` returns `(text, stripped)`; the backend puts the flag on the call result it hands to the client, and the **pipeline** counts strips in `RunManifest.counts["think_stripped"]` (round 9 D9-21; `llm_calls.parquet` keeps exactly its 13 columns and `CallRecorder.record` has no flag). The test model (Qwen2.5) is not affected; the rule is unit-tested on the request builder.

**The LLM cache lives only in `LLMClient`.** Key exactly as interfaces.md §8 (`stable_hash(model,
prompt_id, prompt_version, rendered messages, temperature, max_tokens, seed, response_format)`; interfaces.md wins). Namespace
`llm`. On a hit, return the stored `LLMResponse` with `cached=True` and do not charge the budget.
`cache: KVCache | None` (in-memory dict in tests; `DiskKVCache` from T1.8 in production).

**Provider policy (free-only).** `build_backend(ref: ModelRef, *, policy: LLMPolicyConfig)` resolves the LiteLLM provider prefix.
Allowed by default: `openai_compatible_local` (llama.cpp / any local OpenAI-compatible server,
mapped to LiteLLM `openai/` with `api_base`), `ollama` (the A40 Ollama servers; replaces `hosted_vllm`, round 10 D209; local, not EXTERNAL, for the data guard), `github` (GitHub Models). Anything else
→ `ConfigError("provider '<p>' not in allowed_providers")` at config load / `build_backend`; the same check at request time in `llm/policy.py` `LLMPolicy.check` raises `PolicyViolation(LLMError)`. Paid providers (anything not listed as free in ADR-0009) are refused unless the config sets `llm.allow_paid: true` (default false) **and**
lists them in `allowed_providers`. The canary/private-data block for external providers is added in
T5.1.

**Model id format (R11 Y3.3, D221; Y3.1, D219).** Configs, `ModelRef.id`, the catalogue and `endpoints.yaml` use
**`ollama/<tag>`** (e.g. `ollama/qwen3.8:27b-q8_0`); the bare `<tag>` appears only in Ollama request bodies. The
translation to LiteLLM's model string happens in exactly one pure function in `llm/backends/litellm.py`,
`litellm_model(ref) -> str`: `ollama/<tag>` → **`ollama_chat/<tag>`** (LiteLLM's native `/api/chat` provider, so
`options`/`num_ctx` and `think` apply; never `openai/<tag>` against Ollama, never `/v1/*`),
`openai_compatible_local/<m>` → `openai/<m>` (llama.cpp), `github/<m>` unchanged. A `ModelRef.id` that already
starts with `ollama_chat/` or `openai/` for an A40 model is refused with `ConfigError` naming D221 (the prefix
is a LiteLLM detail, not a config value). T5.1 adds the endpoint lookup and the catalogue `options`.

- [ ] S3 `llm/budget.py` `Budget(max_usd, max_tokens, max_requests=None)` (round 9 X4.5, D9-06: no check-then-act race at the cap):
  - `async def reserve(self, n: int) -> bool`: under an `asyncio.Lock`, reserves `n` requests if `charged + reserved + n ≤ max_requests` and returns `True`; otherwise reserves nothing and returns `False`. Always `True` without a request cap.
  - `async def release(self, n: int) -> None`: under the same lock, returns `n` unused reserved requests (`n` > currently reserved → `ValueError`).
  - `charge(r)`: raises `BudgetExceeded` when cumulative cost or tokens exceed a limit (check after adding). A request charged while a reservation is held consumes one reserved slot and **never** raises for the request cap; an unreserved charge beyond `max_requests` still raises (callers that are not the judge path, e.g. datagen scripts, keep the old behaviour).
  - read-only property `requests_remaining -> int | None` = `max_requests − charged − reserved` (None = no cap; information only, never used for a decision).
  The T1.8 runner reserves 2 per judge call (the call + one possible `complete_json` repair) and releases the unused one. Document the single-event-loop assumption.
- [ ] S4 `llm/recorder.py` `CallRecorder` (in-memory rows, `to_parquet(path)` with columns from interfaces §3 using polars, with an **explicit schema** so a zero-row file has the documented dtypes instead of polars `Null`; every tier-1 run before T5.2b writes an empty `llm_calls.parquet`).

## Interfaces (must match `interfaces.md` exactly)

```python
class LLMBackend(Protocol):
    async def acomplete(self, req: LLMRequest) -> LLMResponse: ...
class LLMClient:
    def __init__(self, backend: LLMBackend, cache: KVCache | None, budget: Budget, recorder: CallRecorder,
                 policy: LLMPolicy, *, fallback: LLMBackend | None = None) -> None   # fallback wired in T5.1
    async def complete(self, req: LLMRequest) -> LLMResponse
    async def complete_json(self, req: LLMRequest, schema: type[T]) -> T
class LiteLLMBackend(LLMBackend)
class Budget:  def __init__(self, max_usd: float | None, max_tokens: int | None, max_requests: int | None = None) -> None
               async def reserve(self, n: int) -> bool   # X4.5: atomic under an asyncio.Lock
               async def release(self, n: int) -> None
               @property
               def requests_remaining(self) -> int | None   # D143; = cap - charged - reserved, info only
               def charge(self, r: LLMResponse) -> None   # a charge against a reservation never raises for the request cap
class CassetteRecorder:                       # llm/cassettes.py (W4.6)
    def __init__(self, dir: Path, mode: Literal["record", "replay"]) -> None
    def wrap(self, backend: LLMBackend | None) -> LLMBackend    # pre-approved addition
class CallRecorder: def record(self, req: LLMRequest, resp: LLMResponse | None, error: str | None) -> None; def to_parquet(self, path: Path) -> None
class PromptRegistry: def get(self, prompt_id: str, version: str) -> PromptTemplate
class LLMClientLike(Protocol): async def complete(self, req: LLMRequest) -> LLMResponse; async def complete_json(self, req: LLMRequest, schema: type[T]) -> T
def build_backend(ref: ModelRef, *, policy: LLMPolicyConfig) -> LLMBackend
class LLMPolicy: def __init__(self, cfg: LLMPolicyConfig, canaries: CanaryRegistry | None = None) -> None; def check(self, req: LLMRequest, provider: str) -> None
```
