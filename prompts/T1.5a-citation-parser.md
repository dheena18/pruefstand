## Goal

One pure, well-tested parser in `core` that finds German and EU legal citations in free text,
including English forms, and normalises them to a canonical string. `ingest` (citation keys),
`metrics` (citation P/R/F1) and `perturb` (citation-style rewrites) all share it, together with a
single law-name map.

## Context

The parser lives in `core` so that `ingest` (below `metrics`) can use it. The law-name map
`core/data/law_aliases.yaml` is the **only** law-name table in the repo. T2.4 adds EU acts to it, and
T4.4 reads it, never a copy. Default granularity (SPEC §4.5) is `§/Art. + Abs. + law`.
`normalise(c, granularity="full")` keeps `S.`, `Nr.` and `lit.` for display.

Matching rule (used by T1.5b, documented here in the docstring of `citations_match`): a predicted
citation matches a gold one when `kind`, `number` and `law` are equal **and** either the gold
`absatz` is `None` or both `absatz` values are equal.

Credit rule (round 9 AI9-17; SPEC §4.5 promises half credit): `citation_credit(pred, gold) -> float` returns
1.0 when `citations_match(pred, gold)`; 0.5 when `kind`, `number` and `law` are equal, the gold `absatz` is set
and the prediction has **no** `absatz`; else 0.0 (a different Abs. is 0.0). `citations_match` stays the boolean
set-membership test; the citation metrics in T1.5b use `citation_credit`.

## Subtasks

- [ ] S1 `Citation` model in `core/citations.py`: `kind: Literal["para", "art"]`, `number: str`, `absatz: str | None = None`, `satz: str | None = None`, `nummer: str | None = None`, `lit: str | None = None`, `law: str`.
- [ ] S2 `extract_citations(text)` handles:
  - `§`, `§§` (lists `§§ 622, 623`; ranges `§§ 1–3` expand to each §)
  - `Art.` / `Artikel` / `Article`
  - English forms for **German** statutes (round-8 W3.12): `Section 622 BGB`, `Sec. 622 BGB`, `s. 622 BGB`, `Section 622(2) BGB` (→ `Abs. 2`), `Section 1 of the Protection Against Unfair Dismissal Act` → `kind="para"`; `Section`/`Sec.`/`s.` followed by a number and a German national law (alias table) → `para`, never `art`. `s.` alone is accepted only when a law follows within the same citation (avoid matching `S.` = Satz inside a German citation)
  - `Abs.` / `Absatz` / `(1)`; `S.` / `Satz`; `Nr.` / `Nummer`; `lit.` / `Buchstabe` / `(f)`
  - `ff.` / `f.`: dropped, base § kept
  - `i.V.m.` and `iVm`: two citations
  - long forms such as "Paragraph 622 des Bürgerlichen Gesetzbuchs"
  - letter suffixes (`§ 5a UWG`)

  A citation without a resolvable law is dropped and logged at debug level.
- [ ] S3 `normalise(c, granularity: Literal["default", "full"] = "default") -> str`:
  - default: `"§ 622 Abs. 2 BGB"`, `"Art. 6 Abs. 1 DSGVO"`
  - full: `"§ 622 Abs. 2 S. 1 Nr. 1 BGB"`, `"Art. 6 Abs. 1 lit. f DSGVO"`
- [ ] S4 `citations_match(pred: Citation, gold: Citation) -> bool` (rule above), `citation_credit(pred: Citation, gold: Citation) -> float` (credit rule above, AI9-17), `parse_one(text) -> Citation | None` (exactly one citation, else `None`).
- [ ] S5 `core/data/law_aliases.yaml` (versioned, `version: 1`): abbreviation → list of aliases, covering long name, genitive forms and English names (incl. "German Civil Code", "Civil Code", "Protection Against Unfair Dismissal Act", "Dismissal Protection Act", "Working Hours Act", "Federal Data Protection Act", "Copyright Act", "Commercial Code"; AI-16). Entries:
  - national: BGB, HGB, KSchG, ArbZG, BDSG, UrhG, VVG, EnWG, UWG, GG
  - EU: DSGVO (`GDPR`, `Datenschutz-Grundverordnung`), KI-VO (`AI Act`, `KI-Verordnung`), `NIS2-RL` (`NIS2`, `NIS-2-Richtlinie`, `NIS 2 Directive`), DSA (`Digital Services Act`, `Gesetz über digitale Dienste`)

  Loaded once through `importlib.resources`.
- [ ] S6 Property tests: the parser never raises on arbitrary Unicode; `normalise(parse_one(normalise(c)))` == `normalise(c)` (idempotence) for generated citations.

## Interfaces (must match `interfaces.md` exactly)

```python
class Citation(BaseModel): kind: Literal["para", "art"]; number: str; absatz: str | None = None; satz: str | None = None
                           nummer: str | None = None; lit: str | None = None; law: str
def extract_citations(text: str) -> list[Citation]
def normalise(c: Citation, granularity: Literal["default", "full"] = "default") -> str
def citations_match(pred: Citation, gold: Citation) -> bool
def citation_credit(pred: Citation, gold: Citation) -> float   # R9 AI9-17: 1.0 / 0.5 / 0.0
def parse_one(text: str) -> Citation | None
```

`granularity`, `citations_match`, `citation_credit` and `parse_one` are pre-approved additions; add them to interfaces.md §5 in this PR if they are missing.
