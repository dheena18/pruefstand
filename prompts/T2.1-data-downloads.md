## Goal

One command (`make data`) downloads every external source into `data/raw/` (git-ignored) at a
pinned version, verifies SHA-256 checksums, and writes `data/raw/MANIFEST.json`. Nothing raw is
ever committed. Layout (binding for T2.2–T2.4): `data/sources.yaml` (pins, committed),
`data/raw/<kind>/<source_id>/…` (git-ignored), `data/raw/MANIFEST.json`.

- GII and EUR-Lex files change when laws are amended: the pin is the download date + sha256; the
  manifest records `version_date` per law when parseable (parsing itself is T2.2).
- HF datasets are pinned by **commit revision SHA** (`revision=`), never `main`.
- Finding live pins needs network access. Pins are evidence "verified on <date>" in `decisions.md`.
- Shared files (`.gitignore`, `DATA_LICENSES.md`): append only, in your last commit. Make targets go into a new `mk/data.mk` (T0.1 convention), never into the root `Makefile`.

## Subtasks

- [ ] S1 `data/sources.yaml`: one entry per source with `id`, `kind` (`gii|hf|eurlex|github`), `url` or
      `repo_id`+`config`+`revision` (40-hex SHA) or `repo`+`commit`, `license`, `license_config`
      (`laws_eurlex | germanquad_derived | oldp_derived | own | download_only`), `redistribute: bool`,
      `attribution`, `files` with `sha256`. MEMERAG: `license_config: download_only`, `redistribute: false`.
- [ ] S2 `data/download.py` (stdlib + `httpx` + `huggingface_hub`): idempotent, resumable,
      `--only <id>`, `--verify-only`, `--update-pins` (re-downloads, rewrites sha256/revision, prints a
      diff; never runs in CI).
- [ ] S3 Checksum verification: mismatch → non-zero exit with source id, expected and actual hash
      (`ChecksumError`). License verification per the license check above (`LicenseMismatch`).
- [ ] S4 `data/raw/MANIFEST.json`: `{source_id: {"pin": revision | download_date, "files": {name: sha256}}}`.
- [ ] S5 `make data`, `make data-verify` targets in `mk/data.mk`; `data/raw/` in `.gitignore` (already there from T0.1; add only if missing).
- [ ] S6 Update `DATA_LICENSES.md` rows for every source (license, attribution text, link, config).
- [ ] S7 CI guard `scripts/check_no_raw_data.py` (wired into `make check` by adding it as a prerequisite in `mk/data.mk`: `file-size: no-raw-data`; the §3 target itself is not redefined): fail if any tracked file
      > 1 MB (lock files `uv.lock` and `pnpm-lock.yaml` exempt; they grow past 1 MB with the later dependency set), or any `*.xml.zip`, `*.parquet`, `*.arrow` is tracked outside the **allowlist** (round 9 X1.3, binding; later tasks commit small result and fixture parquet files there):
      `results/**`, `experiments/**/results/**`, `apps/dashboard/fixtures/**`, `datasets/fixtures/**`, `tests/**/fixtures/**`
      (one constant `ALLOWLIST` in the script; patterns are anchored at the repo root, `**` matches any number of directories). Allowlisted files are still subject to the 1 MB per-file limit. Any tracked file whose path contains a `memerag` component fails **everywhere**, allowlist or not (MEMERAG is download-only, CLAUDE.md §9). Extending the allowlist is an interface change (decision line + this prompt), never a quiet edit.

## Constraints and non-goals

- No parsing of XML/HTML/HF content (T2.2–T2.4). No tenant logic (T2.5).
- No network in unit tests (`respx` / monkeypatched `huggingface_hub`); real downloads are marked `network`.
- Respect source servers: concurrency ≤ 4, `User-Agent: pruefstand-data/<version> (+repo URL)`, retry with backoff.
- BSI IT-Grundschutz stays out until its license is verified (SPEC §2.1 marks it optional).
