## Goal

Any target is called through one `TargetAdapter`; `HttpTargetAdapter` speaks Target API v1; the
OpenAPI contract file exists, and a reusable contract checker validates real responses against it.

## Context

There is **no simulated target** in this project (ADR-0008): every adapter test that needs a target
response uses either (a) the OpenAPI schema + recorded real responses captured from the real
rag-demo (cassettes, see below), or (b) the real rag-demo app once T1.13 exists (`live` marker).
`TargetAdapter` lives in `core.protocols` (T1.1); `TargetConfig`, `HttpTargetConfig` live in
`core.config` (T1.2) — import them, never redefine. `adapters` shares a layer row with `judges`,
`store`, `ingest`, `perturb`, `attacks` and imports only `core`.

Cassettes: until T1.13 lands there is no real target to record from. This task therefore commits
**hand-written example responses that are copies of the OpenAPI examples** under
`packages/pruefstand/tests/contract/examples/` (each file is the plain response body) and records their
origin in `examples/_meta.json` (`{"query_ok.json": {"source": "openapi-example"}, …}`). T1.13
replaces them with responses recorded from the real app (`_meta.json`: `source: recorded`, app git SHA) and
adds the live contract run. Every example must validate against the OpenAPI file.

## Subtasks

- [ ] S1 `schemas/target-api-v1.openapi.yaml` (OpenAPI 3.1) hand-written from interfaces §1.1: `/v1/query` (chunks incl. the optional `used_in_prompt: bool | null`, round 9 X3.14), `/v1/retrieve` (same request; response `{chunks}` only, no `answer`, no generation; an **optional** endpoint for third-party targets, R11 D218), `/v1/info` (incl. `serving`, **static fields only**: engine, engine_version, quantization, gpu, model_sha256; X3.13), `/v1/health` (`status` + optional `stats: {think_stripped, truncated_chunks, requests}`, the runtime counters; X3.13), all optional fields marked nullable/optional, with one `example` per response. (T3.2 generates it from FastAPI and a contract test there diffs against this file.)
- [ ] S2 `adapters/factory.py` `build_adapter(cfg)` registry keyed by `cfg.type` (`http` → `HttpTargetAdapter(HttpTargetConfig.model_validate(cfg.model_dump()))`; unknown → `ConfigError`).
- [ ] S3 `adapters/http.py` `HttpTargetAdapter(cfg: HttpTargetConfig)`: `httpx.AsyncClient` with `timeout=cfg.timeout_s`, header `Authorization: Bearer $<auth_env>` if set (read at construction, never logged); maps HTTP 5xx/timeouts/connection errors → `TargetError(transient=True)`, 4xx → `TargetError(transient=False)`; response validated into `TargetResponse` (invalid JSON/schema → non-transient `TargetError` with ≤ 200-char excerpt). `info()` returns `None` on 404. **`retrieve(req)`** (R11 D218) posts the same `TargetRequest` body to `/v1/retrieve` and validates a `RetrieveResponse`; 404 or 405 → `None` (target without the endpoint; the runner falls back to `query` and counts `retrieve_fallback`), other errors mapped like `query`. `request_id` = `uuid4().hex`.
- [ ] S4 `packages/pruefstand/tests/contract/adapter_contract.py`: reusable `async def check_adapter_contract(adapter: TargetAdapter, questions: Sequence[tuple[str, str]]) -> None` (`(tenant_id, question)` pairs): info is `TargetInfo | None`; query returns a valid `TargetResponse` that serialises to the OpenAPI `QueryResponse`; every chunk `rank` is 1..n without gaps; `request_id` never equals any test-case id; `aclose` is idempotent. Used here with `respx` replaying the example responses, by T1.13 against the real app (`live`), and by T10.3 for framework adapters.
- [ ] S5 `adapters/__init__.py` exports (`HttpTargetAdapter`, `build_adapter`). `TargetError(transient=...)` already exists in `core.errors` (T1.1).
