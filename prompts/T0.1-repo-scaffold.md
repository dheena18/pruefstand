## Goal

A professional, empty monorepo: `uv sync` works, `pruefstand --help` runs, every Make target in
`CLAUDE.md` §3 exists and passes on the empty code base, all seven import-linter contracts exist, and
Claude Code sessions get the project hooks and permissions.

## Context

T0.0 made the repo with the planning pack as its first commit, so you are in a git repo inside WSL2
(Linux file system, HTTPS remote). There is no CI yet (T0.2) and no branch protection yet (T0.5).

**Bootstrap exception (the only one):** T0.1 lands on `main` by direct push, because CI cannot run
before this scaffold exists. Work on the branch, run `make check` and the `_review.md` self-review
locally (`git diff main...HEAD`), then the human runs:
`git switch main && git merge --ff-only chore/T0.1-repo-scaffold && git push origin main`.
From T0.2 on, everything goes through PRs; T0.5 switches protection on. No domain logic here: layer packages are empty
modules with a one-line docstring so import-linter has something to check.

**Shared files.** `Makefile`, root `pyproject.toml`, `.gitignore`, `.env.example`, `.importlinter` and
`DATA_LICENSES.md` are edited by many tasks. To avoid merge conflicts between parallel sessions, the
root `Makefile` only holds the targets from CLAUDE.md §3 and does `-include mk/*.mk`; later tasks add
their own `mk/<area>.mk` and never edit other tasks' files. In other shared files, later tasks only
**append** their own block with a `# --- <task id> ---` comment.
