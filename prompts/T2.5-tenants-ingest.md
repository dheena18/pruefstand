## Goal

`pruefstand ingest --config corpus.yaml` loads all sources, assigns every document to exactly one
tenant (`kanzlei_mueller`, `versicherung_nord`, `stadtwerke_sued`, `shared_public`), chunks, and
writes `corpus/<corpus_version>/<tenant_id>.chunks.jsonl` + `manifest.json` deterministically.

## Context

- Tenant rules (SPEC §3.1), encoded in `corpus.yaml`, not in code:
  - `kanzlei_mueller`: KSchG, ArbZG, ArbSchG, TzBfG, BUrlG, EntgFG, BetrVG, NachwG, MuSchG, ArbGG;
    EUR-Lex 32003L0088, 32019L1152, 32019L1937; OLDP `jurisdiction=Arbeitsgericht`
  - `versicherung_nord`: VVG, VAG, KWG; EUR-Lex 32011L0083, 32024L2853; OLDP insurance decisions
  - `stadtwerke_sued`: EnWG, EnSiG, BSIG; the other 15 EUR-Lex acts (DE + EN)
  - `shared_public`: BGB, EGBGB, HGB, BDSG, UrhG, AGG, GewO, SGB IV, ProdHaftG, UWG, TDDDG, GmbHG,
    AktG, InsO; OLDP decisions of other jurisdictions (the deliberate overlap: BGB contract law is in
    `shared_public`, so law firm and insurer both see it)
  - Every one of the 30 GII laws and 20 CELEX ids from T2.1 appears in exactly one rule (test).
- A document matching no rule → `shared_public` only if `default_tenant` is set; otherwise error.
- Determinism: chunks sorted by `(tenant, doc_id, chunk_id)`; JSON lines with sorted keys;
  identical inputs → byte-identical files → identical `corpus_version`.
- `corpus_version = "<YYYY-MM-DD>.<first 8 hex of sha256(manifest without corpus_version/created_at)>"`,
  computed **only** by `core.fingerprint.corpus_version` (T1.1/T1.10; do not re-implement it in
  ingest). The date is the ingest date passed via `--date` (default today) so CI can pin it.
- Order (no circularity): `pipeline/ingest.py` serialises the sorted chunks per tenant in memory, computes
  per-file sha256 and per-tenant counts, builds the provisional `CorpusManifest`, calls
  `corpus_version(manifest, date)`, then calls `write_corpus(chunks, <--out>/<corpus_version>, corpus_version)`,
  which writes the tenant files + `manifest.json` into that directory, re-checks the sha256 of what it
  wrote and returns the final manifest.
- `TenantPlan` and `CorpusBuildConfig` are already listed in interfaces.md "Where types live"
  (`core.config`); this task defines their fields in `core/config/build.py` (T1.2's package, DEV13-13; re-exported from `core/config/__init__.py`) and writes them into §11.
  The CLI flags `--out` and `--date` are pre-approved additions to §15 (update it in this PR).
- `ingest` and `attacks` are in the same layer row and must not import each other. The pipeline
  `pipeline/ingest.py` is the only place that combines them; leave a clearly named hook
  (`_extra_documents(cfg) -> list[Document]`, empty for now) that T2.6 fills with canary-planted
  private docs and T4.6 with injection docs.
- `Document`, `Chunk`, `CorpusManifest` are imported from `pruefstand.core.models.corpus`.
