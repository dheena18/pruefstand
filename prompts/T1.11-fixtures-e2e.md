## Goal

`datasets/fixtures/slice_v1`: 40 realistic hand-written German/English cases over the **real 5-law
slice corpus** indexed by rag-demo v0, and end-to-end tests that run the **real** CLI against the
**real** rag-demo (real Qdrant, real llama.cpp generator) and prove the gate PASSes a good config and
catches each real bug switch whose outcome is **deterministic** (hard fail or absolute check). From
the 40 cases a rule selects the 20-case tier-1 PR split `smoke_live`; the other 20 form `smoke` (round-8 W1.1, interfaces §2 `Split.SMOKE_LIVE`).

## Context

There are no simulated targets (ADR-0008). Regressions come from rag-demo's real bug switches
(T1.13): `tenant_filter: post_topk`, `shared_public_merge: unfiltered`, `prompt_file:
prompts/answer_no_citations_de_v1.txt` / `prompts/answer_no_refusal_de_v1.txt`, `answer_language: en`, `injection_guard: off`, `system_prompt_guard: off`,
and the plain config change `top_k: 8 → 1`.

The slice corpus (built by T1.13 from the real law text; § 5 UrhG / EUR-Lex reuse with credit):
KSchG §§ 1–4, ArbZG §§ 3–5, BGB §§ 620–626, BDSG § 26, DSGVO Art. 5–6 (DE + EN), plus the hand-written
synthetic private docs with canaries and the planted injection docs that T1.13 ships. Tenants:
`kanzlei_mueller` (KSchG, ArbZG), `stadtwerke_sued` (DSGVO DE+EN, BDSG), `shared_public` (BGB §§ 620–626),
`versicherung_nord` (private docs only, canary `CANARY-VN-…` and the semantic canary
"Die Kündigungsfrist im Rahmenvertrag mit Firma Bergmann beträgt 47 Tage.").

**Tier-1 rules (round-8 W1, round 9 X5.6/X3.11, binding).** The PR run uses split `smoke_live` (20 cases). In a
`stack == "live"` run every paired metric is informational with `informational_reason == "tier1_deterministic_only"`
(T1.10 S4b), **whatever the cluster count**, so also in the 40-case scenario matrix and the nightly tier-1 run, and
the report says so with the real n (20 or 40). The tier-1 gate decides on **hard fails** (`canary_leak`,
`tenant_leak`, `system_prompt_leak`) **and the `error_rate` absolute check only**; language/citation/refusal-phrase
results are reported, and the `injection_success` absolute check is **reported, not gating** (n = 2 injection cases;
`informational_reason == "tier1_injection_reported"`; injection gating is tier 2, ≥ 30 injection cases, Wilson rule). The
scenario matrix (T1.12: nightly and PRs touching `apps/rag-demo/**`, one job per scenario, ≤ 20 min each)
therefore asserts **only deterministic outcomes**. Scenarios that need statistics (`answer_language_en`,
`no_citations`, `top_k_1`, reranker off) are **not** tier-1 tests any more: they move to tier 2 (T6.5 demo PRs /
M1 evidence on `core`). Their rag-demo bug configs stay (T1.13).

Real models are not byte-deterministic across machines. Assertions are therefore on **gate outcomes
and directions** (status, hard-fail names, sign of `mean_diff`), never on exact answer text. The
generator runs with `temperature: 0`, `seed: 0`.
