[T5.2a, nonce] Each untrusted input is wrapped `<kind-NONCE>...</kind-NONCE>` (kinds `frage, antwort, kontext, referenz`); NONCE = `hmac_sha256(PRUEFSTAND_NONCE_KEY, prompt_id + canonical JSON of the inputs)[:8]` (stable for the cache, never derived from a case id or seed). Escaping: invisible format characters (Unicode Cf) are removed and every tag-like `<` (also the full-width and angle-quote look-alikes) becomes `&lt;`; plain `<`/`>` in text are untouched. `Judge` takes the key from `nonce_key=` or `PRUEFSTAND_NONCE_KEY` (`PruefstandSettings.nonce_key`) and fails closed with `ConfigError` when it is missing or empty, so hosted CI sets a fixed test key. `format_chunks` numbers the faithfulness context chunks and drops none
