[T1.7] **Adaptive re-run implemented in `evaluate_gate`** (SPEC §7.2, ADR-0007; it was specified but not coded). After the first bootstrap pass, a testable gated pair with `method == "bootstrap"`, an observed drop beyond `max_drop` and a p within 3 Monte-Carlo SE (`sqrt(p(1-p)/B)`) of a Holm threshold (`alpha/j` or `warn_p/j`, j = 1..m) is bootstrapped again with B = 200 000 from the same `rng`, in pair order, before Holm. Pairs whose drop is not relevant cannot FAIL or WARN and are not refined. R2 (`p = 1/2001`, m = 8) stays unrefined; `BootstrapResult.n_resamples == 200000` marks a refined pair, which the no-op simulation counts (AI13-14).
