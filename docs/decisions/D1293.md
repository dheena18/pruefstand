[T9.1a, lead decision] `action/action.yml` keeps `image: Dockerfile`, a local build, until the first release tag. The pinned GHCR image `docker://ghcr.io/dheena18/pruefstand-action:vX.Y.Z` does not exist before `release.yml` has built and pushed it, and switching earlier would break `action-selftest`.

Until then, release-please's `extra-files` bump only the version strings of `packages/pruefstand/pyproject.toml` and `apps/rag-demo/pyproject.toml`; the root `pyproject.toml` is bumped by `release-type: python`.

The switch to the pinned image is part of the first release PR:
- the `image:` line changes to `docker://ghcr.io/dheena18/pruefstand-action:vX.Y.Z`;
- `action/action.yml` is added to `extra-files` with a version annotation;
- the change stays within the release exemption, whose `image: \S+` line rule already covers it.
