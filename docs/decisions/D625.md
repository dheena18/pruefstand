[T3.6, response] `to_query_response(hits, gen, prompted)` returns the prompted chunks first, in prompt order, with the text the prompt held (cut to `chunk_prompt_tokens`, instruction-like lines dropped while `injection_guard` is on, so the faithfulness judge sees what the model saw), `used_in_prompt: true`; further retrieved chunks follow with `used_in_prompt: false` and their full text. The API logs the prompt chunk ids at DEBUG per `request_id`. `/v1/health.stats` gains `prompt_overflow` (already in the OpenAPI file, D307)
