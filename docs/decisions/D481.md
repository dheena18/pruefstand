[T4.1, exact quotas] A quota is met exactly with whole clusters; when nothing fits the remainder any more, the first skipped cluster is trimmed to the missing unperturbed cases (its other cases are dropped and counted), so a quota fails only when too few cases exist (`DatasetError` naming split, group and counts). `robust_pr` and `rq1`: one base per cluster (the one with the most applicable perturbations, ties by id), bases ranked by applicability score then id; `robust_pr` also needs `robust_pr_min_bases_per_type` bases for each of the 11 names in `SplitPlan.robust_pr_types` and `robust_pr_min_perturbed` perturbed cases. `full`: refusal stratum and blocks stratified by tenant x category (largest remainder), perturbed variants dealt first (balanced per block, at most `full_block_perturbed` each, base in the same block), plain clusters then by (stratum count, block size). The judged subset is stratified by group (answerable / unanswerable / injection, shares as in `core`: 110 / 25 / 15) and by tenant inside each group (P3.4, no `lang`).
