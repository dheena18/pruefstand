[T8.2b, charts] The Diff and Slices charts are hand-written SVG, not Recharts: no new dependency, bars and lines are SVG attributes in percent of the shared domain (never a `style` attribute, ui-spec §7.4), colours and hatching come from CSS classes on the §7.1 tokens. Each chart is a `ChartShell` (`<figure>`, `<figcaption>`, the server-rendered table alternative, a toggle button) around a `charts/*.client.tsx` wrapper that loads the plot with `next/dynamic(…, {ssr: false})` (UI11-22); before hydration and without JS the table is the visible content, afterwards it stays in the DOM visually hidden until "Show as table". The Diff domain also includes 0 so the zero line is always drawn; a chart holds at most 50 rows (`?page`), a slice chart at most 12 bars with the full table behind "Show all n in table". The owner accepts the hand-written SVG instead of Recharts on condition that every chart is accessible: `role="img"` rows with `aria-label`, `<title>` and `<desc>`, a `<figure>`/`<figcaption>`, and a table with the same values always in the DOM; ui-spec §8 states these requirements and the tests check them.
