[T8.2b, number format] `format.ts` rounds on the exact binary value and breaks exact ties half-even, like Python's `format()` (`0.125` → `0.12`, `0.375` → `0.38`, `0.005` → `0.01`, `2.675` → `2.67`). `Intl.NumberFormat` cannot do it in either rounding mode: it rounds the shortest decimal text (`0.005` is a tie, `2.675` rounds up), so the helper rounds with `toFixed` plus a tie check and hands the already-rounded number to `Intl` for the locale's separators. The 2-decimal formats (`formatValue`, `formatPlain`, `formatDelta`) are tested on ties, near-ties and non-finite values; values from 1e13 up use plain `toFixed` (no tie can exist there); an `-0.004` reads `-0.00` like Python. `formatTokens`, `formatCost` and the en grouping of large values are not covered (follow-ups).
