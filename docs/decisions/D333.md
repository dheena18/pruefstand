[ops, VM finding 2026-10-31] The GitHub Models credential used **outside GitHub Actions** is `PRUEFSTAND_GH_MODELS_TOKEN` (fine-grained PAT, Models: read only; `.env`/`.env.example`), never `GITHUB_TOKEN`: `gh` prefers `GH_TOKEN`/`GITHUB_TOKEN` env vars over its stored login, so a `.env` exported into the shell made `gh` lose repo/Actions access (HTTP 404 on `actions/runs`). `GITHUB_TOKEN` means only the Actions-provided token inside workflows. Code (LiteLLM `github/`, live tests, cassette recording, datagen, `PruefstandSettings.gh_models_token`) reads only `PRUEFSTAND_GH_MODELS_TOKEN`; workflows that call GitHub Models set `env: PRUEFSTAND_GH_MODELS_TOKEN: ${{ github.token }}` with `permissions: models: read`. Never export `.env` wholesale into a shell that runs `gh`; if needed `env -u GITHUB_TOKEN -u GH_TOKEN gh …` (CLAUDE.md §3, runbook, secrets.md) |
