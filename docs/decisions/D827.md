[T4.3, tests and cassettes] No real support call can be made from the VM (D604): the unit tests drive the real `LLMClient` and backend against the scripted loopback server (plumbing, D788), the copy rules run on real BGB / ArbZG chunks of `slice_v1`, the embedding tests use fixed numeric vectors (`scripts/tests/test_filter_qa.py` also covers the embedding client with `httpx.MockTransport`). Cassettes of the REAL support model are recorded by the dataset stage of `make cassettes` into `tests/cassettes/dataset/support/` (`PRUEFSTAND_RECORD_SUPPORT=1`, GitHub Models id from `PRUEFSTAND_SUPPORT_TEST_MODEL`, default the second datagen model); `test_filters_cassette.py` replays them and is skipped until the owner or lead has recorded them. The live embedding test needs `PRUEFSTAND_EMBED_URL`.
