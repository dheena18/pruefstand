[T8.4 slice 2, public mode wired] `RagConfig.public_mode` (default false) and `public` (`PublicLimits`: rate, daily caps, concurrency, timeout, allowed origin) select the public demo; `apps/rag-demo/configs/rag.public.yaml` is the tier-1 profile plus public mode with `reranker: off`. `DEMO_*` and `TRUSTED_PROXY_HOPS` environment variables override the limits (`Settings`, empty values ignored); neither the new fields nor the variables enter `config_hash` while public mode is off. `rag_demo.public.middleware.PublicGuard` (pure ASGI, only installed in public mode) runs, for `POST /v1/query`: kill switch, rate limit, an 8 KB body cap, strict validation and a server-made `request_id`/`top_k` (client values replaced), the concurrency slot, the budget reservation, the app under `DEMO_TIMEOUT_S`; `/v1/retrieve` gets the kill switch and the rate limit. HTTP errors of the app are mapped to the public bodies; the one addition to the code set is `server_error` (503) for any other backend failure, an interface addition documented in interfaces section 16. The test-only `POST /v1/_test/reset` is registered only with `DEMO_TEST_RESET=1`, answers 204 to loopback peers when idle, 409 `busy` while a generation runs and 404 otherwise, and is hidden from OpenAPI. `Settings` ignores empty environment values for every field (`env_ignore_empty`), because `.env.example` leaves the `DEMO_*` values empty. The guard turns any crash before the response starts into a public `server_error` body (with CORS), and reads every `X-Forwarded-For` header line.
