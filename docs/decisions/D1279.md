[T6.3 S1, review of #227; adds to D1277] All variant runs of a noise arm pair with the same reference `main` run, so their paired diffs share that run's noise. Pooling sigma_d over them is still unbiased for the variance, but they are not independent replicates: no interval on sigma_d may count them as such. `reorder` permutes the keys of nested sections too, and a test pins it: the `generation` section changes order for some seed.
