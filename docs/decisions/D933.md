[T5.4, calibration nonce] The calibration and the anchors render judge prompts with fixed public nonce keys (`rq2-calibration-public-nonce`, `rq2-anchor-public-nonce`): the inputs are public or local data, not written by an attacker, the rendered anchor prompts are stored in the repo anyway, and a fixed key keeps the judge cache reproducible. Production runs keep `PRUEFSTAND_NONCE_KEY` (D703).
