[T4.2, cross-check] `--cross-check <fraction>` regenerates a seeded share (at least one candidate) with the second model, whose family must differ from the datagen model's and is never `qwen` or `gemma`, and writes both candidates side by side (`CrossCheckRow`) to `cross_check.jsonl`; it runs only when generation finished, and rows from an earlier run are reused, so a re-run sends no request. The request cap applies per client (datagen and second model each).
