[T5.4, drift step] `pipeline/judge_drift.py run_judge_drift` is synchronous and wraps the given backend in its own `LLMClient` without a cache, so anchors are never answered from the cache. `judge_drift.json` (`DriftFlag`) gains the optional fields `changed`, `threshold`, `a0`; `epoch` stays the bumped cache epoch. A passing re-run clears the flag of an `ollama/` judge (`clear_drift`, no `judge_epoch` bump); a hosted judge's flag stays until a passing re-calibration (`experiments/rq2/recalibrate.py`: bumps `epoch`, calls `clear_drift`). `is_drift(..., threshold)` refuses a threshold below the N3 default. Flip rate (S11): each anchor judged >= 4 times at concurrency 4 with the cache bypassed; a flip is a later run differing from run 1; f_upper = 95 % Wilson upper bound over n x (runs - 1) comparisons; `a0` = agreement of run 2 with run 1 (recorded only, D253); `drift_threshold` = smallest c >= 5 with P(Bin(50, f_upper) >= c) <= 1 %. `pruefstand judge-drift` reads threshold and `a0` from `calibration_status.yaml`; without an anchor file it logs `skipped` and exits 0.
