[T1.12, live-e2e plan and cost] Job `prepare` decides which jobs run: PRs that change only docs (`docs/`, `prompts/`, `tasks/`, `*.md`, `mkdocs.yml`) skip `live` and `scenarios` with success (ci-cd.md section 1, "docs-only PRs exit early"); the scenario matrix runs on `schedule`, `workflow_dispatch` and PRs that touch `apps/rag-demo/**`, `.github/workflows/live-e2e.yml` or `.github/actions/live-stack/**` (so a change to the workflow exercises it). `workflow_dispatch` gets the input `job` (`all` or `scenarios`; `dose-response` and `judge-anchor` are added by their tasks) next to `probe_quota`, which runs only `quota-probe`. The aggregate `gate` accepts a skipped job only when the plan says so. `prepare` holds `actions: read` for `gh cache list` (allow-list entry in `scripts/workflow_policy.py`)
