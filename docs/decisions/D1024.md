[T8.3, accessibility fixes found by axe, D139] The matrix found two real defects, both fixed in the dashboard: (1) links inside running text were indistinguishable from text without colour (axe `link-in-text-block`, serious; Tailwind's preflight removes the underline), so `globals.css` sets `a { text-decoration: underline }` (component classes that set `none` for nav items keep it); (2) the `sr-only` status words in table cells were absolutely positioned against the page, so a 360 px viewport scrolled horizontally (scrollWidth 473 > 360) on every run page with a table; `.table-wrap` is now `position: relative`. Not fixed here (follow-up for the report task): `report.html` scroll containers are not keyboard-focusable (axe `scrollable-region-focusable`); the matrix disables only that rule for `report.html` rows
