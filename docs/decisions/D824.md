[T4.3, near-duplicates] `dedupe` embeds the question texts (function injected; the script uses the tier-1 CPU embedding server through `scripts/filter_qa_embed.py`: TEI `POST /embed` or native Ollama `POST /api/embed`), visits candidates in the order of `case_id_of` (the stable id of `to_test_case`) and drops one whose cosine to an already kept one is `>= max_sim` (0.9, boundary included); the kept list is ordered by id, so any input order gives the same list. `dedupe_report` also returns the dropped. A wrong shape or a zero vector is a `DatasetError`.
