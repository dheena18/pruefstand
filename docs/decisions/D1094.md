[T6.2b, backup] `infra/gate-executor/host/backup.sh --repo <dir> [--keep N]` writes one `age`-encrypted tar (git bundle of every branch of the private checkout, which `backup.yml` fetches with `fetch-depth: 0`, plus `$PRUEFSTAND_DATA_ROOT/baselines/`) as `*.partial`, renames it and keeps the newest 8 dated directories. The plaintext bundle exists only in a `mktemp -d` directory (umask 077) for the length of the run. The recipient comes from the private repo's Actions variable `vars.AGE_RECIPIENT` (a public key, not a secret; owner decision via the coordinator), not from `runner.env`; the script refuses a value that is not `age1` + 58 lowercase characters (exit 2) and an unusable data root (exit 1). No step puts a token on a git command line.
