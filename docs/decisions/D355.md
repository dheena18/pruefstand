[T1.4, scope notes] (a) The backend does not retry: `num_retries=0`, hard timeout, transient/permanent errors mapped to `LLMError(transient, status)`; bounded retry with backoff and `Retry-After` is T5.1 (`test_retries.py`). (b) `LLMPolicy` already carries the external-provider data guard (private-doc prompt prefix, canary token / fact in the messages) because a policy that silently lacks it is unsafe; T5.1 keeps its `test_policy_guard.py` rows. (c) The LLM cache key is the prompt text of the task (without `model_version`); adding `model_version` (D113) is T5.1. (d) `LiteLLMBackend.think_stripped` counts stripped `<think>` blocks; surfacing it in `RunManifest.counts` is T5.1/pipeline work. (e) A cassette miss raises `LLMError("cassette miss: <hash> (no cassette for <prompt_id>)")`, satisfying both the prompt and interfaces §3. (f) `validate_policy_config` enforces the provider names and `allow_paid` at load (left open by T1.2). (g) `github/` uses `https://models.github.ai/inference` explicitly (the host the T0.6 quota probe uses): LiteLLM 1.103.10's built-in GitHub default host `models.inference.ai.azure.com` does not resolve from the VM. From the VM, `models.github.ai` answers every path with `200 text/plain OK` (2026-11-01), so the optional GitHub Models live test could not be verified there; it runs in Actions with `models: read` once `live-e2e.yml` exists (T1.12). (h) Review hardening: cassettes keep only allow-listed headers and every recorded text must pass `assert_no_secrets` (recording refuses); `LiteLLMBackend` enforces a hard `asyncio.wait_for` timeout and bounded responses (transport byte cap + answer length vs `max_tokens`); `extract_json_object` is linear (256 KiB cap, `raw_decode`); `LITELLM_MODE=PRODUCTION` stops `import litellm` from loading `.env`; `LLMPolicy(..., external_datagen=False)` denies DATAGEN to external providers by default (interface addition, T4.2 passes `True`); `openai_compatible_local` endpoints must be loopback / RFC1918 / compose services; `cassettes.yml` is split into a read-only `record` job and a `push` job without repository code (allow-list entry `(cassettes.yml, push)`).
