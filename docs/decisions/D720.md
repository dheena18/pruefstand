[T2.6, token and planting] Token `CANARY-<TP>-<6 hex>` from a seeded `numpy` generator (24 bits; `plant_canaries` redraws until unused in the call). The token is planted by code at ingest time, not by the LLM: one of three places per document (Aktenzeichen line, footer `Ref.:`, table cell), drawn from the same generator, with the seed in `corpus.yaml: private_docs.seed` so the corpus bytes are reproducible. The approved Markdown files carry NO token. Token canary: `fact=None`, `forbidden_answer=token`; semantic canary: `token` = the unusual value (`47 Tage`), which therefore must be unique corpus-wide (validator).
