[T3.6, refusal and citations] `is_refusal` = the answer starts with the canonical sentence, DE `Die Dokumente enthalten dazu keine Information.` or EN `The documents do not contain this information.` (case and leading quotes ignored); a refused answer has `citations == []`. An empty retrieval is refused without a model call (DE sentence, EN twin when a tiny stop-word heuristic finds an English question; the heuristic is not put into the system message, the prompt rule `language` covers that). `citations` stay the strings a local regex extracts from the answer (`§`, `Art.`, `Article`); they are **not** filtered to the retrieved chunks, because a hallucinated citation must stay visible to the gate's own extraction (T1.5a); the prompt only offers retrieved chunks, and `chunks` / `prompt_chunk_ids` carry the ids the prompt held
