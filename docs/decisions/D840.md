section: "Task decisions (appended)"

[test hygiene] Unit tests never assert on wall-clock time. A scales-linearly test compares CPU-time (`time.process_time`) ratios with `testsupport.timing.assert_scales_linearly` (`packages/pruefstand/tests/testsupport/timing.py`: min of 5 runs, small and big input alternately, GC off during the call, limit `1.25 * scale ** 1.5`, i.e. 10x for a 4x input where linear costs 4x and quadratic 16x); a finishes-within-N-seconds test uses `cpu_budget(N)` with N at least 10x the CPU time measured on the VM, a counter, or an injected clock; a test whose point is a timeout or a lock wait injects a fake clock, blocks on an event instead of a sleep, or uses a real margin of 10x or more. No test is deleted, skipped or quarantined for being slow under load.
