[T6.2a, owner request for M4 prep] Two host scripts for the runner's env file `/home/pruefstand/runner.env` (`docs/ops/secrets.md`), both run by the owner as user `pruefstand` with the script on stdin (`sudo -u pruefstand bash -s -- /home/pruefstand/runner.env < infra/gate-executor/host/<script>`), so `pruefstand` needs no access to the owner's checkout and no agent ever reads the file. `runner-env-names.sh` prints only variable names (`NAME`, `NAME (empty)`; `export` prefixes, comments, blank lines and quoted multi-line values handled; any other line is reported by number only), never a value. `runner-env-keys.sh` appends `PRUEFSTAND_NONCE_KEY` and `PRUEFSTAND_CANDIDATE_API_KEY` when missing, each `openssl rand -hex 32` as `secrets.md` says, written straight from `openssl` into the file (never into a variable, an argument or the terminal); it never changes an existing line, is idempotent, creates a missing file with mode 0600 and refuses (exit 2, file unchanged) a symlink, a mode other than 600/400, a file owned by another user, or a key present with an empty value. Both scripts turn tracing off. Tests use fake files under a temp dir only.
