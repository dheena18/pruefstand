[T5.2b, consistency] `perturbation_consistency` gets the base answer from a per-run `BaseAnswers` (a `ContextVar` set by `Runner.run`): each base case resolves its answer right after the target call (`None` when it has none or ran in `retrieve` mode), a variant awaits it. Tasks are created bases first, so under the semaphore a variant never waits for a case that cannot start (also at `concurrency=1`); a variant whose base is not in the run, errored or has no answer is `not_applicable` (`base_answer_missing`). The base answer is the `referenz` block
