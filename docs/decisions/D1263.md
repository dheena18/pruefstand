[Owner decision 2026-11-16; T7.3 RQ1 grid, T7.1a M03] The second RQ1 embedder and the M03 ("weaker embedding model") tier-2 embedder are both **multilingual-e5-large-instruct**, the model behind the catalogued Ollama tag `jeffh/intfloat-multilingual-e5-large-instruct:f16` (accepted by the owner instead of the plain `multilingual-e5-large` the T7.3 prompt names). Both run on the **VM CPU, never on the cluster**: the cluster models disk has about 4.7 GB free (D451), so nothing is pulled to or removed from it for RQ1/M03, and the generator is never touched. CPU path: the repo's existing CPU embedding server, the TEI CPU container of the tier-1 `live` profile (`ghcr.io/huggingface/text-embeddings-inference:cpu-1.9`, same pinned digest as `docker-compose.yml` service `embed`; rag-demo `EmbedCfg.engine: tei`), as a second service in the VM `gpu` profile next to `rerank-cpu` (no auth, no secrets, D217; reached by name on the candidate network; inside the 24 GB CPU-model budget of the VM, Z7: about 2.2 GB fp32). Pin (Hugging Face, checked 2026-11-16, licence MIT): `intfloat/multilingual-e5-large-instruct` revision `274baa43b0e13e37fafa6428dbc7938e62e5c439`, `model.safetensors` SHA-256 `dd6b6e4f52db0a7aff83a13d10e6c5342ef9f6ab799bad3221f4b35ef390fa85` (1 119 825 680 bytes), `tokenizer.json` SHA-256 `f59925fcb90c92b894cb93e51bb9b4a6105c5c249fe54ce1c704420ac39b81af`; the pin goes into a manifest like `infra/models/live-models.yaml` (weights downloaded by TEI on first start into the model cache, hash checked, never committed). **Prefixes:** the instruct variant does not use `query: ` / `passage: `; queries take `Instruct: <task>\nQuery: ` and passages no prefix (model card). The T7.3 integration therefore sets `query_prefix: "Instruct: Given a German legal question, retrieve the statute passage that answers it\nQuery: "`, `doc_prefix: ""`, `max_input_tokens: 512`, and corrects the provisional Ollama catalogue entry (it carries the plain e5 prefixes) or marks it not used. The T3.1b-style identity check (cosine >= 0.99 on 20 passages against the reference checkpoint) applies to the TEI deployment. Wall time: CPU indexing of the RQ1 collections is slower than GPU; T7.3 measures and records it in `experiments/rq1/README.md`. Prompts `T7.3-rq1-grid.md` (Embeddings, S0) and `T7.1a-mutations-core.md` (M03 row) are updated to match.
