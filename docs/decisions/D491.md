[T3.4, idempotence and metadata] A re-run on an existing collection upserts the same UUID5 point ids (`uuid5(NAMESPACE, chunk_id)`, namespace unchanged from T1.13), deletes points whose id is no longer in the corpus (`must_not has_id` filter) and rewrites the collection metadata (`PATCH /collections/<c>`): `corpus_version`, `tenants`, the analyzer fingerprint and `avgdl` (D461) plus `embed_model`, `dim` and the index-time `truncated_chunks`. An existing collection with another dense size is refused (`IndexMismatchError`, drop it first). Payload = `chunk_id, doc_id, tenant_id, citation_key, section, lang, text, source, is_attack, version_date`; payload indexes `tenant_id` (keyword, `is_tenant=true`), `lang`, `doc_id` (keyword), `is_attack` (bool)
