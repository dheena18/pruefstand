[T2.5] `write_corpus(chunks, out_dir, corpus_version, *, sources=None)`: the keyword-only `sources` (source id to pinned version) is an additive extension of the interfaces.md signature, because the manifest needs it and the signature had no other way to receive it. Files are written to a `.<name>.partial` staging directory, re-hashed, then renamed; an existing version directory must hold exactly the same bytes (versions are immutable); a symlinked output directory or parent is refused; lines are compact sorted-key JSON and `U+2028`, `U+2029`, `U+0085` are written as escapes so `str.splitlines()` readers see one record per line
