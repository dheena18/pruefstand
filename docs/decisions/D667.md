[T8.2b, slices page] Slice rows are classified with the same predicate as the gate rows (`assignTable` / `assignBlock` take the two fields `gated` and `informational_reason`; `kind` only picks the `Source`: `absolute` → absolute_checks, `informational` without a reason → notable_slices, else decisions). Tier 2 has the sections Gated and Informational; tier 1 has `checks` (the Gated group), `reported` (block R) and `informational` (J, I, N), each listed only when it has rows. Every section has its own dimension and metric choice in the URL (`?d_<section>=&m_<section>=`; metric empty = one chart per metric); the default dimension is the first of tenant, lang, category, perturbation, perturbed_all, tags, other, overall.
