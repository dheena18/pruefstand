[Owner request; amends D1085, D1266, D1268] `scripts/sync_executor.sh` takes the file modes of the synced executor code from the public tree (`git ls-tree` modes at the tag, then `git update-index --chmod=+x|-x` in the temporary clone), so the executable host scripts stay `100755` in the private repo even when the maintainer runs the script from Windows Git Bash, whose clones use `core.fileMode=false` and would store every new file as `100644`. Every successful run (PR opened, `--init`, `--dry-run`, nothing to sync) ends its output with the VM step `sudo -u pruefstand git -C /home/pruefstand/pruefstand-gate pull --ff-only`, to run once the private `main` has the change.
