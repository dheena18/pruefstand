[T3.5, query shape] Prefetch limits `retrieval.prefetch_k` 50 per leg, fusion `{"rrf": {"k": 60}}` sent explicitly (`retrieval.rrf_k`; Qdrant 1.16+ uses k = 2 when none is given), `retrieval.hybrid: false` = one filtered dense prefetch (fused with RRF too, so scores stay comparable). The fused query asks for `max(top_k, rerank.top_n)` hits when `reranker: on`, else `top_k`. Both fields are new `RagConfig` sections (`RetrievalCfg`), part of `config_hash` with their defaults, so every config hash changes once with this task (like D463)
