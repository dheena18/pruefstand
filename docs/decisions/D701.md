A score out of range, a string or float score, an empty reason or an extra key is invalid, so it takes the one repair call of `complete_json` and then raises `LLMError`. Normalised score = raw / max (0 / 0.5 / 1 and 0 / 1). `judges/output.py` `SPECS` is the one metric -> prompt id / variables / scale table
