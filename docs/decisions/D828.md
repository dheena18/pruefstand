[T4.3, review fixes of #76] (1) `check_evidence` no longer uses `evidence._scope`: a cited Absatz that the chunk does not have accepts the text before the first marker only for a LATER chunk (`#k`, k > 0) and only for an Absatz that comes before that marker, never the heading of the first chunk; an Absatz in no chunk of the norm is `evidence_not_in_cited_absatz` (the text exists in the cited chunk but outside the cited Absatz); ranges `Abs. 1 bis 3` / `1-3` / `2 und 3` are expanded (`absaetze_of`); evidence is compared in NFC, shorter than 3 words is `evidence_too_short`; a missing citation / evidence / unparsable citation is a drop reason (`citation_missing`, `evidence_missing`, `citation_unparsed`). (2) Copy rule on `copy_words`: umlauts and `ß` folded (`ue`/`ss`), norm references (`§ 622`, `Abs. 2`, `Satz 1`, `Art. 5`) and law names / abbreviations removed before the n-grams are formed. (3) `meta_reference` covers a pointer (`dieser`, `obig`, `genannt`, `vorliegend`, `zitiert`) + Text/Abschnitt/Auszug/Paragraf/Vorschrift/Norm and article + Text/Abschnitt/Auszug, but not `der Text eines/von ...`. (4) Support verdict: `score` must be 0 or 1 and not a boolean, `reason` optional/null; the `<abschnitt>` tag is defused case-insensitively. (5) `scripts/filter_qa.py`: thresholds out of range are refused (exit 2); the embedding server is probed before the support stage; each support verdict is appended to `support_verdicts.jsonl` as it arrives and reused by the next run for the same support model; the generator model is taken from the ledger (or `--generator-model`, which must be in it); the kept file is `filtered.jsonl` only for a complete run (`filtered_partial.jsonl`, `filtered_nosupport.jsonl` otherwise), never-judged candidates go to `filtered_unjudged.jsonl`, and `summary.json` gets a `filter` entry (support, models, complete). (6) `dataset.filters` is the public facade re-exporting every filter; the support code moved to `filters_support.py`.
