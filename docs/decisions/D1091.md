[T6.2a S9, how runner.env is loaded] `pruefstand-runner.service` reads the executor settings and secrets with `EnvironmentFile=/home/pruefstand/runner.env`, so systemd's rules apply, not bash's: one `KEY=VALUE` per line, lines starting with `#` are comments, no `export` keyword, no variable expansion (`$HOME`, `${X}` stay literal) and no command substitution, quotes only around a whole value (they are removed), no line continuation tricks beyond systemd's. The runner process and every job it starts inherit these variables; no host script `source`s the file (a test checks both). Documented in the runbook, §0 step 6. Restart the unit between jobs after an edit.
