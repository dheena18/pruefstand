[CI, GitHub Models retired 2026-07-30; workflow change, OWNER merges] `.github/workflows/cassettes-models.yml` is removed, not retargeted: the VM model of D1200 is not reachable from GitHub-hosted runners and the public repo has no self-hosted runner (CLAUDE.md §7), so those recordings now run on the VM (`docs/ops/cassettes-actions.md`, D1201). The tier-1 GitHub Models judge is dropped: `live-e2e.yml` job `live` has no `models: read`, its `Judge mode` step sets `PRUEFSTAND_JUDGE_MODE=skipped` for every event (was: forks only), the gate step no longer maps `PRUEFSTAND_GH_MODELS_TOKEN`, and the nightly tier-1 judge-drift step and the T0.6 `quota-probe` job (input `probe_quota`) are removed. `scripts/workflow_policy.py` `MODELS_READ_FILES` is empty, so any `models:` permission fails the guard. Judged metrics stay informational in tier 1 (D94-D97), now always `skipped`; the configs keep their judge ids (they are not called). Left for a follow-up: the dead helpers `scripts/models/gh_models_budget.py`, `apply_models_artifact.sh`, `quota_probe.py` and their tests, and the `github/` judge ids in `examples/live/*.yaml`. Review round: `pipeline/judge_mode.py` never auto-selects `github` (a `live` run is `skipped` even with an old `PRUEFSTAND_GH_MODELS_TOKEN`) and refuses `PRUEFSTAND_JUDGE_MODE=github` as retired; the `probe_quota` plumbing in `prepare` is removed; the PR-comment judge line says "skipped (GitHub Models retired, D1202)". The second-family PR review (CLAUDE.md §7, `prompts/_review.md`) no longer names `gh models run`: it runs with a free provider of CLAUDE.md §5 (the VM CPU model or an Ollama model on the cluster under the lock); which one is an OWNER DECISION, still open. Replaces D900 and the CI parts of D333 and D927 (the release mirror stays usable through `PRUEFSTAND_GII_MIRROR`).
