[T8.1, export safety, D542] `export-dashboard` sanitises every run with `sanitise_run`, then masks and cleans the hard-fail `evidence` of `gate.json` (registry masker `store.sanitise.text_masker` + `report._html_text.clean`, 199 characters). The output refuses to be written when any file contains `CANARY-`.
