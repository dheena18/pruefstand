[T6.1] `index.json` (schema 1) maps fingerprint -> ref -> runs (oldest first, newest = current: run_id, manifest_sha256 of the `<ref>/manifest.json`, promoted_at, git_sha). Retention (`prune_baselines(root, keep, unused_days, now)`, disk only) is "last 20 per fingerprint across refs": the newest `keep` `history/<run_id>` per fingerprint by `promoted_at` (the history entry of every current baseline is pinned), fingerprints with no promotion for more than `unused_days` (measured by `promoted_at`, not mtime) lose everything but their `main` and `release-b<k>` directories (a quiet `main` baseline is never aged out, so the next PR does not fall to `no_baseline`), unreadable manifests and names that are not safe path components are left alone, symlinks are never followed; `GitBranchBaselineStore.prune` then reconciles the index with the disk in one commit (nothing to remove: no commit)
