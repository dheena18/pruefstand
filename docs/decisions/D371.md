[T2.4] EUR-Lex `Document.text` is a block format (record-separator marker line `\x1eART 6\tTitle` / `\x1eREC 12\t`, then the body lines); all control characters are removed from the source text, so input cannot forge a marker. One `Document` per (act, language), `version_date` = Official Journal publication date, `metadata` = `celex`, `citation_en`, `attribution`, `layout` (`eli`, `flat`, `legacy`), `content_hash`. Three layouts are read because the pinned CELLAR files differ: 18 acts use ELI divs (`art_N`, `rct_N`), 2002/58/EC and 2003/88/EC are plain `<p>` lines; unprefixed `ti-art` and flat siblings are supported and tested. A DE/EN pair with different Article or recital sets is skipped and counted (`misaligned`), never half-loaded.
