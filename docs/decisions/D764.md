[T4.6, rotation and retired list] `rotate_canaries(registry, release, rng)` seeds a child generator from `rng` and a hash of `release`, issues new `CANARY-<TP>-<6 hex>` tokens (disjoint from the old ones) and new semantic facts from `fact_templates` (same document, same kind, new value), and returns the old canaries as retired. `datasets/canaries/retired.json` is `[]` in v1; `RetiredCanary` has the documented `{token, tenant, fact, retired_in}` plus the optional `probe_question` and `forbidden_answer` (additive: the contamination probe needs them); `retire()` appends without duplicates, `load_retired()` validates. Writing the file stays the maintainer's step from T9.1b's artefact (D93).
