[T1.8, round-4 review; replaces the rejected footer-only text] `RunManifest.artifact_sha256` (new field, interface change) holds the SHA-256 of `results.parquet`, `responses.jsonl` and `scored.jsonl`, set by `write_run`. `read_run` stream-hashes each file (regular non-symlink file, size cap, then hash) and raises `StoreIntegrityError` (new subclass of `StoreError`) on a mismatch or missing entry, before any parser sees it; `results.parquet` is never parsed by `read_run` (a hostile footer aborts polars). Error texts show only model field names, never run ids or keys from files. `DiskKVCache`: blob-only rows, key length cap 512, the constructor raises `StoreError` for a corrupt or locked cache (T1.10: no cache). The runner parses cache blobs with one typed model, treats any failure as a miss, validates unicode on hits and skips a failing cache for the rest of the run
