[cassettes-models.yml, real GitHub Models calls in Actions] D604 (no GitHub Models call from the VM or the cloud sandbox) is worked around by `.github/workflows/cassettes-models.yml`: manual `workflow_dispatch` only (inputs `target` = `indomain_dev` \| `t42_dataset` \| `t45_perturb` \| `all`, `budget_calls`), top-level `permissions: {}`, job `contents: read` + `models: read`, no secret, `PRUEFSTAND_GH_MODELS_TOKEN: ${{ github.token }}` only on the three steps that call models (D333). It runs the existing commands (`indomain_cli generate/check/assemble`, `record_cassettes.sh --dataset`, new `--perturb`), commits nothing and uploads an artefact (`cassettes-models-<run>`, SHA-256 list); `scripts/models/apply_models_artifact.sh` verifies and copies it for a normal PR. A separate file, not `cassettes.yml`: that one is the weekly llama.cpp job whose `push` job is pinned by the T0.2 guard tests; the only guard changes are `cassettes-models.yml` in `MODELS_READ_FILES` (and the two tests that mirror it). Budget: `DAILY_CAP` 120 calls per UTC day (ledger in `actions/cache`, `scripts/models/gh_models_budget.py`), `budget_calls` per run, a stage that does not fit the day is skipped, `indomain_cli --pause-s` paces calls to 13 per minute. Cache: in-domain answers keyed by the prompt hash and extended by every run, T4.2/T4.5 cassettes by an exact content hash (hit = no call); 7-day eviction, 10 GB cap (`docs/ops/cassettes-actions.md`). T4.5 judge in Actions = a GitHub Models model of another family (no A40 there; the id is in `meta.json`); an A40 re-recording stays a lead decision. The schedule is a commented-out daily cron, not enabled (owner decides). Review round (security): the job runs on `main` only (`if: github.ref == 'refs/heads/main'`); the ledger is a SOFT counter (a lost cache entry resets it), a corrupt ledger fails closed, `budget_calls` is per run over all stages (0 is refused), the quota day is the run's start date; pacing is per tier (4.5 s low, 6.5 s high, free-tier limits unverified assumptions); `apply_models_artifact.sh` refuses symlinks and unlisted files, installs only listed allow-listed files with mode 0644 under size caps. Merging is the owner's (adds `models: read` to a public workflow).
