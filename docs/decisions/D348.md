[T1.5b] `citation_grounded` takes its evidence from the retrieved chunk **text** only: API v1 `RetrievedChunk` carries no `citation_key` (only the indexed `Chunk` has it), so the `citation_key` branch of the R9 X3.2 definition cannot be evaluated. A chunk whose text omits its own § header therefore counts its citation as ungrounded; adding an optional `citation_key` to `RetrievedChunk` (additive API v1 change, T1.1/T1.3/T3.x) is a follow-up proposal, not done here.
