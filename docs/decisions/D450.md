[T6.1, dependencies] `duckdb` (the `RunIndex` of ADR-0003: SQL over all runs) and `zstandard` (the `responses.jsonl.zst` / `scored.jsonl.zst` of the baseline layout, with a bounded decompressor) are added to `packages/pruefstand`; the stdlib has neither. `RunIndex` keeps tables `runs` and `results`, ingests a run only after `read_results` verified its hashes (rows come from `scored.jsonl`, never from a parquet on disk), skips runs that fail verification with a warning, and answers `query` on a read-only connection with `enable_external_access` off (no file read, no file write)
