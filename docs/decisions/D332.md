[ADR-0019] Cluster scripts are copied by the VM **over SSH** into `$CLUSTER_DATA_ROOT/pruefstand-bin` on the cluster (`deploy-cluster-bin.sh`, `*.partial` + `mv`, `SHA256SUMS`; a few KB) and run as `ssh $CLUSTER_SSH_HOST bash $CLUSTER_DATA_ROOT/pruefstand-bin/<script>.sh`; `health.sh` exit 14 = that dir out of date. The owner's `~/start-ollama.sh` is the start script of record: T3.1a's `start-ollama.sh` reuses a running server and otherwise runs `setsid nohup ~/start-ollama.sh > $CLUSTER_DATA_ROOT/ollama.log 2>&1 < /dev/null &`, never a second server and never its own env; no pid file (server found by `pgrep` + `:11434` listener); `cluster.env` holds only expected values and paths
