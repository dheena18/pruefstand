[T3.3, hashing and index fingerprint] `SparseEncoder` token id = `xxhash64(token) mod 2**31` (dependency `xxhash`, BSD-2, replaces T1.13's blake2b mod 2**20); BM25 TF with k1 1.2, b 0.75; IDF from Qdrant `modifier: idf`. The `Indexer` computes `avgdl` (mean token count per chunk) from the corpus before encoding and stores it in the collection metadata with an `analyzer` fingerprint (hash scheme, dim, k1, b, `compound_split`, `stemmer`, `fold_umlauts`, digest of lexicon and stopword files). `create_app` compares the fingerprint with its own before it answers a query and answers 503 "…; re-index" on a missing or differing one (no silent dense-only fallback). Old indexes are invalid: default collection, snapshot and integration slice are renamed `slice_v2`
