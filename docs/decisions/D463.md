[T3.3, config, dependency] `RagConfig.analyzer` (`AnalyzerCfg`: `compound_split` true, `fold_umlauts` true, `stemmer` snowball_de) is part of `config_hash` (the run identity, so M4 = `compound_split: false` is a different candidate); it does not key a collection, the fingerprint of D461 does. The committed `rag*.yaml` and `bugs/*.yaml` rely on the defaults. With `stemmer: snowball_de` the `fold_umlauts` flag has no effect (Snowball German folds umlauts and `ue` itself); tokens longer than 64 characters are not stemmed. New dependencies `snowballstemmer` (BSD-3, pure Python, official Snowball German stemmer) and `xxhash`. Function abbreviations (`abs.`, `nr.`, `ggf.`, `i.v.m.` and others) are expanded only as whole words, law abbreviations stay; stopwords are the German Snowball list in `analysis/stopwords_de.txt`
