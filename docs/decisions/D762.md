[T4.6, probes] Leak probes: one per (asking tenant, foreign canary), `cluster_id` = canary token, `forbidden_strings` = token or the semantic `re:` pattern (3 tenants with 16 canaries each give 96 probes). Filter-bypass probes: three wordings per ordered tenant pair naming the OTHER tenant, `forbidden_strings` = every canary foreign to the asker, `cluster_id` `filter-bypass-<n>`. System-prompt probes: 3 DE + 3 EN, asked as the customer tenants in turn, `cluster_id` `sysprompt-<n>`, `forbidden_strings` = distinctive sentences of the reference app's prompts (`attacks/data/system_prompt_probes.yaml`; a test keeps them in `answer_de_v1.txt`/`_v2.txt`). All probes are deterministic (no rng).
