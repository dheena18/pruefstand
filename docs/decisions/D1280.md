[T6.3 S5 offline, before the noise runs] How `experiments/noise/outputs.py` builds the `results/noise` files.

**Paired diffs.** They are made with the gate's own pairing (`gate.tables.pair_runs`) and slices (`gate.slices`). So worst-fill, judge-error flags, the X3.6 rule (perturbed cases only in `perturbed_all`) and the diff orientation (negative = worse) are exactly the gate's.
- Only metrics with a `max_drop` and only the `gated_slices` are kept.
- The columns are `arm, kind, pair, split, metric, slice, cluster_id, diff`.

**`mde.csv`** has one row per metric × slice × split, and a second row for a key is refused. This is the contract #226's `load_sigma` reads (core / overall).
- The columns follow the T6.3 prompt, plus `clusters_needed`.
- `n_applicable_clusters` is the measured distinct cluster count of the slice over all pairs of the split.
- `m_family` is the number of gated rows of that split.
- `detectable_drop` and the 1.5δ check use the pooled σ_d(churn); `detectable_drop_noop` uses σ_d(no-op); `sigma_d_repeat` is reported as the floor.
- A row exists only where a churn σ_d exists.

**Other files.**
- `sigma.csv` adds the `split` column to `analyze.sigma_table`.
- `replay.csv` has one row per arm, with rates and Wilson CIs.
- `timings.csv` has `stage, seconds, budget_s, within_budget`.
- `paired_diffs.parquet` is zstd-compressed. It is refused, and not left behind, at 1 MB or more.
