[T2.6, generation] `scripts/generate_private_docs.py` uses the catalogue's standard judge model (`gemma3:12b`) through the Ollama path, local providers only and never family `qwen` (`ConfigError`, before any call); it refuses to run without `PRUEFSTAND_LOCK_HELD=1`. Catalogue options are enforced by the backend, so `num_predict` 384 caps a document at about 150 words and retries differ only by a stricter hint in the prompt. The answer must end with `[ENDE]` (cut-off detection), start with `# `, hold the fact once, no `CANARY`, be German. Drafts land in the git-ignored `datasets/private_docs/_drafts/<tenant>/`; existing drafts are skipped (resumable). No cache is used for private text.
