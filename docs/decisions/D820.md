[T4.3, overlap = copy rules] `check_overlap` compares WORDS: NFC, lower case, soft hyphens removed, every run of non-word characters is one separator, so NFD spellings and punctuation do not hide a copy. `overlap = shared question 6-grams / question 6-grams` against each source chunk (a pair is checked against both); `ngram_overlap` when it exceeds `max_ngram_overlap` (default 0.0 = no shared 6-gram), `long_copy` when a shared word run has `long_copy_words` (default 8) or more words. A question shorter than 6 words has no 6-gram. The thresholds are `FilterConfig` fields (`core.models.dataset`), not constants; `check_overlap` takes `max_ngram_overlap` positionally (interfaces §14) and `long_copy_words` as a keyword. This ENFORCES the rule the generation prompts only ask for (D781).
