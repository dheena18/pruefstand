[T8.4 slice 4, found by the T5.4e pilot] The e2e instance `rag-demo-e2e` no longer uses host port 8091 / 18091: 18091 is the port of `scripts/models/vm_llm.sh` (the VM judge and datagen model, `VM_LLM_PORT`), so a Try-it run and an RQ2 session clashed. `scripts/demo/try_e2e.sh` now computes `E2E_PORT = 8092 + PORT_OFFSET` (18092 on an agent dev stack); the port map in `docs/engineering/docker.md` section 3 has a row for it, and `scripts/tests/test_e2e_port.py` fails if the default (offset 0 or 10000) equals any other port in that map or in `.env.example`. The remaining `${E2E_PORT:-8091}` default in `infra/deploy/demo/compose.yml` and the `docs/ops/secrets.md` row are an owner-path follow-up (the script always sets `E2E_PORT`, so nothing breaks meanwhile).
