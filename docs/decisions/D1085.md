[T6.2a S10, `scripts/sync_executor.sh`] The maintainer copies the executor code into the private repo only from an **annotated** tag `executor-<YYYYMMDD>[.N]` whose commit is on `main` (`MAIN_REF`, default `origin/main`); any other name (incl. `v*`), a lightweight tag or a tag off `main` exits 2. Synced: `infra/gate-executor/{orchestrator,llm-proxy,host}` (same paths, replaced as a whole so removals propagate) and `infra/gate-executor/workflows/*` into the private repo's `.github/workflows/` (where they run); nothing else of the private repo (held-out canaries, `executor-state`, baselines index) is touched. A file `SYNCED_FROM` records `<tag> <commit>`. The script pushes branch `sync/<tag>` and opens a PR in the private repo (`gh pr create`); `--dry-run` shows the diff and pushes nothing. It needs the owner's credentials for the private repo, so only the owner runs it (agents' VM token cannot reach the private repo). Tested against local git repos with a stubbed `gh`; ShellCheck clean.
