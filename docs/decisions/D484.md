[T4.1, HF export layout] `export_hf` writes `<license_config>/<split>.jsonl` (one folder per config, only splits with rows) and `README.md` rendered from `dataset/card_template.md.j2`; the YAML header lists `configs:` (config_name + data_files, no extra keys, so `load_dataset(repo, config)` keeps working) and a top-level `config_licenses:` mapping config -> SPDX id, with `license: other`. Attribution texts are in `dataset/licenses.py` (same wording as DATA_LICENSES section 3). Refused: a directory under `datasets/private/`, an unknown licence config; filtered: cases tagged `heldout`, `held_out` or `private`. `--dry-run --out DIR` builds the layout directly in `DIR` (never inside the dataset directory); `export_hf(..., dry_run=True)` uses `dir/hf_export` (git-ignored). The upload needs `HF_TOKEN` from the environment, creates the repo as private unless `--public`, and builds the layout in a temp dir.
