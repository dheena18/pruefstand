[T8.4 slice 1, public demo building blocks] `rag_demo.public` holds the pure, in-process pieces of the public demo mode: `limits.Limiter` (token bucket per client key, per-key and global daily counters, concurrency cap; a refused request does not use up a daily count; a restart resets everything), `limits.client_key` (the `X-Forwarded-For` hop `TRUSTED_PROXY_HOPS` places from the right, the TCP peer for 0 or when the header is shorter; IPv6 keyed by its /64 prefix; `CF-Connecting-IP` never read), `budget.DailyBudget` (worst-case `max_tokens` reserved before a generation, settled afterwards, capped at the reservation; per UTC day; request cap too), `killswitch.demo_disabled` (`DEMO_ENABLED=false` or the flag file, read per call) and `errors.Rejection` (the fixed `{code, message, retry_after_s}` body, HTTP statuses of interfaces section 16). The messages are fixed English texts, so a body never carries the question or a stack trace. Wiring into the app (middleware, validation, `rag.public.yaml`, the test-only reset) is the next T8.4 slice.
