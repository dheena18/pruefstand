[ADR-0019, setup log §6, interface] Data root `PRUEFSTAND_DATA_ROOT=/mnt/pruefstand` is a **plain directory on the VM disk** (500 GB zvol on TrueNAS): no NFS, no mount unit, no service dependency; `CLUSTER_NAS_ROOT` is dropped. Preflight (`health.sh` exit 16) checks it exists, is writable by `pruefstand` and has ≥ 20 GB free, else `infra_error="data_root_unavailable: <detail>"` (replaces the earlier NAS kind); heartbeat field `data_root_ok` (+ `_false_since`) replaces `nas_mounted`. Backups: TrueNAS periodic snapshots of the VM zvol (daily, keep 14) + the weekly `age`-encrypted bundle copied to the owner's laptop
