[Scorecard #4 SecurityPolicy, #5 PinnedDependencies] `scripts/cloud/connect-vm.sh` no longer runs `curl https://tailscale.com/install.sh \| sh`: it downloads the static tarball `https://pkgs.tailscale.com/stable/tailscale_<version>_amd64.tgz` (version and SHA-256 pinned in the script; the hash equals the published `.sha256` file and was verified locally), checks the hash before unpacking, fails closed on a mismatch and installs `tailscale` and `tailscaled` to `/usr/local/bin`. Chosen over the signed apt repository because the cloud session runs as root without systemd and uses userspace `tailscaled --state=mem:`, so no apt keyring or package-manager state is needed; curl carries the D926 retry flags. `scripts/tests/test_connect_vm_pinned.py` guards it. Root `SECURITY.md` added (private vulnerability reporting, pre-1.0 support, 7/30-day response, scope).
