[security fix F8, `baseline promote`] `--allow-failed-gate` needs `--reason TEXT` (1-500 chars, exit 2 otherwise). When the flag waives something, the promotion stores `PromotionOverride` {by = `GITHUB_ACTOR` or the OS user name, at = UTC now, reasons = what the guard would have refused, note = `--reason`} in the baseline's `manifest.json` (current and history) and in its `index.json` entry (`by` is a label for the audit trail, not authentication: anyone who can run the command can set `GITHUB_ACTOR`); `--reason` with control or format characters (Unicode `C*`) or without the flag is exit 2; `BaselineStore.put` gains keyword `override` (core `core.models.baseline`); the key is omitted when None, so plain promotions keep their bytes. Supersedes the 'structlog warning only' of D881 for the record.
