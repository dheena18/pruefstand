# Milestone M1: tier-1 `live-e2e` green on a real PR

M1 (tasks/TASKS.md) is reached when the tier-1 workflow gates real pull requests with the real stack: rag-demo,
a llama.cpp CPU generator (thinking off), CPU embeddings and Qdrant on a GitHub-hosted runner. T1.12 delivers
the workflows; the three demo pull requests (S7) need a person and a `push: main` baseline, so the links below
are filled in by the owner after the merge.

## What runs

| Workflow | Job | What it proves |
| --- | --- | --- |
| `live-e2e.yml` | `live` | 20-case `smoke_live` run on the real stack, gated against the latest successful `main` push run (`live-baseline`); one PR comment. Decides on hard fails and `error_rate` only. |
| `live-e2e.yml` | `scenarios` | The five deterministic bug-switch scenarios of T1.11, one parallel job each (nightly, dispatch, PRs touching `apps/rag-demo/**` or the live workflow). |
| `live-e2e.yml` | `gate` | The aggregate, required check `live-e2e / gate`. |
| `action-selftest.yml` | `selftest` | The Action image against the same stack: a good run passes, `tenant_filter: post_topk` exits 1. |
