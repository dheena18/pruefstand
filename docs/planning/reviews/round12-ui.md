## What is good

- One Pages writer, downloads only by run id, rollback by run id, and an assembly step that cannot
  overwrite `docs/`. The previous "latest artefact" class of bugs is gone.
- The `_empty` placeholder with `validate_data.mjs` rule 8 and `noindex` is a clean answer to the
  export's empty-params limit.
- Report CSP self-hashing in `render_html` removes the drift between old reports and new builds.
- The derived fixtures go through real `pruefstand gate`, so `F-NO-BASELINE` and `F-JUDGE-SKIPPED`
  are true outputs, not hand edits.
