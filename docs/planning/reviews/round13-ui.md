## What is good

- `workflow_run` with `run-id: github.event.workflow_run.id` removes the whole "which run do I deploy" class of bugs,
  and `deploy.yml` holds no deploy permission.
- The size cap is enforced three times (export, `validate_data.mjs` rule 9, `verify_dashboard_export.py`) plus the
  800 MB assembly check, with `D-MANY` dated so the newest-20 rule is exercised by real fixtures.
- `basepath-smoke` with a "every same-origin request starts with `/pruefstand/`" listener is the right test for this
  bug class, and T8.5 reuses its helper.
- The demo no longer needs any token. The demo-ready mark is a public job result, so nothing expires.
