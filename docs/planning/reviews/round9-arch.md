## Public/private boundary

No private-repo credential is in the public repo: the public repo holds only release-time secrets in
protected environments plus `GITHUB_TOKEN`, and `executor-health.yml`/`deploy.yml` read the data repo
anonymously. Data crossing into public places: sanitised dashboard export (canary-probe cases dropped,
no chunk text), redacted PR comments, `heartbeat.json`. The open paths are the candidate → PR-comment
channel for held-out data (R9-09) and plaintext backups leaving GitHub (R9-08).
