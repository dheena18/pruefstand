## Assumptions (stated, not verified here)

- GitHub-hosted standard Linux runner for public repos = 4 vCPU (2 physical cores with SMT), 16 GB RAM, x86 AVX2,
  CPU model varies between jobs (AMD EPYC / Intel Xeon). **verify** at T0.6.
- GitHub Models free tier ("low" models): about 15 requests/min, **about 150 requests/day**, 5 concurrent, ~8 000 input
  / 4 000 output tokens per request; "high" models about 10/min and 50/day. Limits depend on the account plan and change
  over time. **verify** (T0.6 measures them, but see AI-01).
- llama.cpp on 2 physical cores, 1.5B Q4_K_M: prefill about 60–150 tok/s, decode about 15–25 tok/s. **verify**.
- A40 (PCIe, no FP8): 14B AWQ prefill a few thousand tok/s batched; 27B AWQ roughly half of that. **verify** in T3.1b.
- German subword tokenisers give about 1.5–2 model tokens per German word. The repo's `count_tokens` (regex
  `\w+|[^\w\s]`) undercounts model tokens by about 1.3–1.8×.
- Licence facts quoted below are from memory as of mid-2026 and are marked **verify** where it matters.
