Kanzleihandbuch der Kanzlei Müller, Abschnitt Fristenkontrolle. Jede Frist wird im Fristenkalender mit
einer Vorfrist von einer Woche erfasst. Die Fristenkontrolle wird täglich von der Büroleitung
abgezeichnet. Fristen, die auf einen Samstag, Sonntag oder Feiertag fallen, werden auf den davor
liegenden Werktag vorgezogen.
