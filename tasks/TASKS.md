worktrees, different files — see "Parallel lanes").

Legend — **Who:** `AI` (Claude Code session), `H` (you, human), `AI+H` (AI builds, you review/label).
**Est.:** focused hours for an AI session incl. review. **Model:** suggested Claude model for the
session (`Opus` for design-heavy/statistics/security, `Sonnet` for standard implementation).
**Env:** what the task needs beyond the dev shell — `GPU` (A40 cluster, reached from the VM through the
`autossh` tunnels), `NET` (internet), `DOCKER`, `HUMAN`. All sessions run on the VM via VS Code Remote-SSH
(R10 Z7; WSL2 optional).
**Tier:** `core` (needed for the MVP and the RQ results) or `optional` (do only if time allows; the
project is complete without it).

Timeline: **20–26 weeks part-time** one session at a time; MVP (M4) around week 12–14. Week ranges below
overlap because lanes run in parallel. With the multi-agent wave plan: **≈ 12–15 weeks**, M4 ≈ week 8–10.

**Waves:** the schedule for running up to 6 agents in parallel (one task = one worktree = one PR, merge
order, shared-file hunks, checkpoints) is [`tasks/PARALLEL-PLAN.md`](PARALLEL-PLAN.md). This file stays the
source of truth for tasks and dependencies; if the two disagree, this file wins and the plan is fixed.
Progress is ticked in [Progress](#progress) by each wave's checkpoint PR.

There are **no fake models or fake targets** in any task (ADR-0008, real-stack testing): every e2e test
and every CI gate run uses real Qdrant, the real rag-demo, real LLMs (llama.cpp on CPU, Ollama on the
A40s (R10), GitHub Models free tier) and real data. Free providers only.

Milestones: **M1** tier-1 `live-e2e.yml` green on a real PR: real rag-demo + ≤ 2B llama.cpp generator on the
real 5-law slice, split `smoke_live`, deterministic gate, informational GitHub Models judge, real PR comment,
and the deterministic demo PRs (whitespace → PASS, `tenant_filter: post_topk` → hard FAIL) behave as expected;
the statistical demo (reranker off) moved to tier 2 / M4 (D98) (end P1) · **M2** real RAG app answers with
citations (end P3) · **M3** v1 dataset released (end P4) · **M4 (MVP)** real gate blocks a bad PR via
the private gate executor on the A40s (end P6, ~week 12–14) · **M5** experiments reproducible (end P7) ·
**M6** public demo (end P8) · **M7** release (end P9).
